Cover/Slip/Designate

Use this menu to make settings for covers, slip sheets, or chapter pages.

Available functions differ depending on the printer or printer driver you are using.

Restore Defaults

Restores the settings on this menu to the default settings.

Front Cover

Prints the first page on a slip sheet or inserts a blank sheet as the front cover.

Printing Only the First Sheet on a Different Type of Paper

Input Tray:

Select the tray containing the paper to use for the front cover.

Print Mode:

Select one of the options for the cover.

Leave Blank

The cover sheet is not printed on. Printing begins on the second sheet.

One Side

Only one side of the cover sheet is printed on. If you have specified 2 sided printing, selecting this will ensure only one side of the cover sheet is printed on.

Both Sides

Both sides of the cover sheet are printed on. This option is available only for 2 sided printing.

Paper Type in Bypass Tray...

Specify the type of printing medium you want to use when using bypass tray paper as the front cover sheet. Available media types differ depending on the printer you are using.

Back Cover

Prints the last page on a slip sheet or inserts a blank sheet as the back cover.

Printing the Back Cover on a Different Type of Paper

Input Tray:

Select the tray containing the paper to use for the back cover.

Note:

  • Depending on the printer you use, the input tray selected for the front cover may be always used for the last sheet. In this case, the Input Tray: list is unavailable.

Print Mode:

Select one of the options for the back cover.
Depending on the printer you are using, the available items may vary.

Leave Blank

The back cover sheet is not printed on.

Print on Back Cover

Prints on the back cover sheet.

Print on Outer Back Cov.

Prints on the back side of the back cover sheet.

Paper Type in Bypass Tray...

Specify the type of printing medium you want to use when using bypass tray paper as the back cover sheet. Available media types differ depending on the printer you are using.

Insert Slip Sheet After Every Page

Inserts a separator sheet after every printed sheet.

Inserting Different Paper between Pages

Input Tray:

Select the tray containing the paper to use for the slip sheets.

Note:

  • The slip sheet function is not available if the same input trays are selected for both print pages and slip sheets.

Print Mode:

Select whether or not to print on slip sheets.
Depending on the printer you are using, the available items may vary.

Leave Blank

Inserts a blank sheet as a separator.

Print on Slip Sheet

Prints on slip sheets.

Paper Type in Bypass Tray...

Specify the type of printing medium you want to use when using bypass tray paper as the slip sheet. Available media types differ depending on the printer you are using.

Designate/Chapter

You can divide a document into chapters and print the first page of each chapter on different paper. You can also select the print mode for the first page of each chapter. (Designate/Chapter)
In addition, you can print the selected pages on different paper. (Designated Sheet Print)

Using Designate/Chapter Function

Details...

Opens the Designate/Chapter Details dialog box where you can configure the detailed settings.
