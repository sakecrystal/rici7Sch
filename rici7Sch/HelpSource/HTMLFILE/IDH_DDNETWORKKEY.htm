Driver Encryption Key Dialog Box

Use this dialog box to enter the driver encryption key already set on the printer.

The encryption function encrypts the login password when sending it to the printer.
Depending on the printer you are using, this function may not be available.

Driver Encryption Key:

Enter the driver encryption key already set on the printer.

Reenter the Confirmation Key:

Enter the driver encryption key again for confirmation.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
