Register Custom Paper Size Dialog Box

Use this dialog box to register custom paper sizes. Up to ten custom paper sizes can be registered. Depending on the printer you are using, up to 100 custom paper sizes can be registered.

The graphic illustrates which dimension is width " A ", and which dimension is length " B " in relation to the feed direction.

Custom Paper Size List:

Displays the registered custom paper names and sizes.

Edit

Make settings for custom paper sizes.

Name:

In Custom Paper Size List:, select an unused name, and then change it as necessary.

Measurement Unit:

Select inch or mm as the units of measurement.

Width:

Enter the size of the paper edge (A) that is vertical relative to the feed direction of the printer.

Length:

Enter the size of the paper edge (B) that is horizontal relative to the feed direction of the printer.

Modify

Click to update the Custom Paper Size List: with the settings specified here.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Help

Displays Help for the dialog box opened.
