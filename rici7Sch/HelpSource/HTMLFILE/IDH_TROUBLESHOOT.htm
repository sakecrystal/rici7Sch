Troubleshooting

If print results are not as required when using the RPCS printer driver, try the procedures below.

Note:

  • If you reinstall the printer driver or install the latest printer driver, you may be get correct printing result that you require, uninstall the old version before installing the new one.

Characters or images do not print out, or if they do, they are printed incorrectly

  • Select the Spool Data in EMF Format check box on the Driver Options menu.

  • Select Raster in the Vector/Raster: list on the Print Quality:Advanced menu.

Some extended characters are corrupted, or not print correctly

  • Select Raster in the Vector/Raster: list on the Print Quality:Advanced menu.

Graphic data cannot be printed, or if possible, it is not printed correctly

  • Change the Resolution: setting on the Print Quality:Standard menu.

  • Select Advanced Settings for Adjust Image Quality/Color in the Print Quality:Standard menu and change the setting for Dithering:, and then print.

  • Select the Spool Data in EMF Format check box on the Driver Options menu.

  • Select Raster in the Vector/Raster: list on the Print Quality:Advanced menu.

Patterns are not printed

  • Select the Shift Shading Pattern check box on the Print Quality:Advanced menu.

  • Select the Enlarge Shading Pattern check box on the Print Quality:Advanced menu.

  • Change the Resolution: setting on the Print Quality:Standard menu.

  • Select Advanced Settings for Adjust Image Quality/Color in the Print Quality:Standard menu and change the setting for Dithering:, and then print.

  • Select the Spool Data in EMF Format check box on the Driver Options menu.

  • Select Raster in the Vector/Raster: list on the Print Quality:Advanced menu.

Even though the fill color of the pattern is the same, the color changes according to the place or page

  • Change the Resolution: setting on the Print Quality:Standard menu.

  • Select Advanced Settings for Adjust Image Quality/Color in the Print Quality:Standard menu and change the setting for Dithering:, and then print.

Though K (Black) in the Gray Reproduction: list is selected, black and gray areas of documents are printed in full color.

  • Select Vector in the Vector/Raster: list on the Print Quality:Advanced menu.

  • If an image contains gray data, select the K (Black) for Gray Pixels Only in the Gray Reproduction: list on the Adjust Image Quality/Color tab.

Images cannot be printed, or if possible, they are not printed correctly.

  • Select the Spool Data in EMF Format check box on the Driver Options menu.

  • Select Raster in the Vector/Raster: list on the Print Quality:Advanced menu.

  • Select the Change Data Processing check box on the Print Quality:Advanced menu.

  • Change the Resolution: setting on the Print Quality:Standard menu.

Print quality is unsatisfactory

  • Change the Resolution: setting on the Print Quality:Standard menu.
  • If a document contains images, change Print Priority: on the Print Quality:Standard menu.

Print speed is slow

  • Select the Spool Data in EMF Format check box on the Driver Options menu.

  • Select a lower resolution in the Resolution: list on the Print Quality:Standard menu.

  • If a document contains images, change Print Priority: on the Print Quality:Standard menu.

  • If a document contains images, select the Change Data Processing check box on the Print Quality:Advanced menu.

  • When printing in black and white, select Raster in the Vector/Raster: list on the Print Quality:Advanced menu. Alternatively, select the Change Data Processing check box on the Print Quality:Advanced menu.

  • Change Job Load Distribution: on the Driver Options menu.

It takes time for computer to be released from the printing process

  • Select the Spool Data in EMF Format check box on the Driver Options menu.

  • Select a lower resolution in the Resolution: list on the Print Quality:Standard menu.

  • Select Shift Load to Printer in the Job Load Distribution: list on the Driver Options menu.

  • If a document contains images, select the Change Data Processing check box on the Print Quality:Advanced menu.

  • When printing in black and white, select Raster in the Vector/Raster: list on the Print Quality:Advanced menu. Alternatively, select the Change Data Processing check box on the Print Quality:Advanced menu.

Clicking Print button makes application close / Application freezes

  • Select Raster in the Vector/Raster: list on the Print Quality:Advanced menu.

  • Select the Change Data Processing check box on the Print Quality:Advanced menu.

  • Select the Spool Data in EMF Format check box on the Driver Options menu.

Printing PDF files results in a size error

  • Select the Near Standard Size check box on the Driver Options menu.

Do not print or unexpectedly rotate the image by 90 degrees and print it

  • The paper size and type of input tray may not match the physical settings.
    See Setting Up Options, and configure the correct settings in the Accessories tab.

Blank areas appear on multiple pages or page order is incorrect

If you are printing through the LPR port or Standard TCP/IP port, use the following procedure to change the settings.

  1. In the Devices and Printers window, open the printer properties dialog box.

  1. Click the Advanced tab.

  2. Click Start printing after last page is spooled and Print spooled documents first, and then click OK.

  3. Make test prints using various applications and files.
