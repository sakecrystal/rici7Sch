Using ICM

Color correction is available using the Windows ICM function.

ICM is a color management system that adjusts colors between I/O devices. Use this function to produce print results with colors as close as possible to those shown on the display.

Note:

  • This function is available only for color printers.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Standard menu on the Detailed Settings tab.

  3. Select Advanced Settings for Adjust Image Quality/Color.

  4. Click the Details... button to open the Details dialog box and click the Adjust Image Quality/Color tab.

  5. In the Color Profile: list, select Use ICM.

  6. In the Color Profile Method: list, select By Printer Driver.

  7. In the ICM Intent: list, select the color image rendering method.

  8. After making any other necessary settings, click OK to close the printing preferences dialog box.

  9. Start the print job.
