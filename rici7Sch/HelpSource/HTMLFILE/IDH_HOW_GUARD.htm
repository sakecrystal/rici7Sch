Using Data Security for Copying Function (Destroy the Image and Print Gray)

Use this function to embed a text and background pattern in confidential documents.

If a document with an embedded copy guard pattern is copied, scanned, and/or stored in a machine with the Copy Data Security unit, the image of the page to be printed is destroyed, and replaced with a solid gray image.

Depending on the printer you are using, this function may not be available.

Note:

  • Use the Unauthorized Copy Prevention function to make the background pattern and text clearly visible when an unauthorized document is copied, scanned, printed, and/or stored in the machine.

  • This function requires that the Copy Data Security unit be installed on the printer.
    Depending on the printer you are using, you may need an MFP that comes with the Copy Data Security unit. For details, see the operating instructions provided with the printer.

  • If an unauthorized document is copied, scanned, printed, and/or stored in a machine without the Copy Data Security unit, a warning message will be printed on the printed copy instead of the copy's color being completely gray.

  • For details about data security for copying function and effects, see the operating instructions provided with the printer.

  • Printing with this function takes longer than normal printing because more data is processed.

  • Depending on the data security for copying settings, the driver's prevention pattern may be overwritten by the printer's pattern.

 

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Effects menu on the Detailed Settings tab.

  3. Select the Unauthorized Copy Prevention check box.

  4. Select Data Security for Copying in Unauthorized Copy Prevention Type.

  5. Click Details... to open the Data Security for Copying Details dialog box.

  6. Select the text type for the prevention text in the list.

  7. If you select User Text in Text Type: list, enter a user text using up to 64 single-byte characters.

  8. To change the font, font style and font size, specify from Font:, Font Style: and Size:.

  9. To change the angle, specify a value in Angle:.

  10. Select a position to enter the prevention text in Position:.

  11. To repeat text, select the pattern in Repeat:.

  12. Specify the line spacing in Line Space:.

  13. To print the text in outline form, select the Outlined check box.

  14. Click OK to close the dialog box.

  15. After making any other necessary settings, click OK to close the printing preferences dialog box.

  16. Start printing.
