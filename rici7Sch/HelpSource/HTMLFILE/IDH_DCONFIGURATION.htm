Configuration/About Tab

Specify the tab configuration.

Available functions differ depending on the printer or printer driver you are using.

Default Tab:

Select the default tab which is displayed when you open a Printing Preferences screen.

Default Menu for Detailed Settings:

Select the default menu which is displayed when you open the Detailed Settings tab.

One Click Preset List Type:

Specify a view style when you open the Frequently Used Settings tab.

Printer Properties

Opens the printer properties dialog box.
You can configure the options installed on the printer or manage one click presets on the Accessories and Advanced Options tabs of the printer properties dialog box.

About

Provides copyright and version information.

Printer Diagnostic Correction Tool

If the printer does not print, click this button to start the tool to diagnose and fix the problem.

Web Image Monitor...

Starts Web Image Monitor.

Web Image Monitor allows you to check the printer's status, manage jobs, and change settings, via a Web browser. For details, see the Web Image Monitor Help.

Note:

  • This function is available only if your computer is connected to the printer by the standard TCP/IP (IPv4/IPv6), WSD (IPv4), IPP (IPv4), or Ridoc IO Navi (IPv4/IPv6/IPP) port.
    This function will be unavailable if the IPv6 address you specify includes a number following the % symbol at the end of the address (also known as the "zone identifier" or "scope ID"), or if your computer is connected to this machine through network printer sharing.
