Printing a Document Using Only Specific CMYK Colors

When you print a color document, usually the cyan, magenta, yellow, and black colors are used. However, you can choose to use only specific CMYK color(s) when printing.
For example, you can use magenta and yellow for printing a document in red only, or magenta and cyan for blue only, or yellow and cyan for green only. As a result, printing costs will be reduced.

Note:

  • This function is available only for color printers.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Advanced menu on the Detailed Settings tab.

  3. Select the color or colors you want to use in the Separate into CMYK, then Print in Designated Color Only area.

  4. After making any other necessary settings, click OK to close the printing preferences dialog box.

  5. Start the print job.
