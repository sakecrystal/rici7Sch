Driver Options

Use this menu to provide functions related to controls specific to the driver.

Available functions differ depending on the printer or printer driver you are using.

Restore Defaults

Restores the settings on this menu to the default settings.

Spool Data in EMF Format

Select the check box to set the spooling format to EMF. This will reduce the time the printer takes to release itself from the printing process. Changing the spooling format might also resolve print problems.

Note:

  • Depending on the application you are using, this function might be disabled even if you select the EMF spool check box.

  • If this function is disabled, the following functions are not available:
    Layout:     - Page Order:
    Booklet:
    Reverse Order Printing
    Watermarks:

Job Load Distribution:

This allows you to assign the load share of the print process between the printer and printer driver (computer).

Shift Load to Driver

Maximizes the load share of the print process on the printer driver. Select this if the print process takes time and the computer has a high capacity to process the job.

Shift Load to Printer

Maximizes the load share of the print process on the printer. Select this if the print process takes time and the computer has a low capacity to process the job.

Restore Last Emulation

Returns to the setting before the print job.

Near Standard Size

When a document is scanned for printing, its size might be detected as larger than the original and a printer error might occur.

Select the check box to prevent this problem.

Use Application Zoom

Use the application's zoom.

Select the check box when lines are not printed in Microsoft® or Excel® files.

Always apply COLOR to dmColor setting for appLication

When you perform black-and-white printing for color documents created by using Microsoft® PowerPoint® and so on, some objects are filled with black when printed.
If this is the case, enable this function. You will obtain print results you require.

Display Preview and Print Screen

Select the check box to display the preview screen to check print previews. You can also change some of the settings on the screen.

Note:

  • This function may not be available in a "Point and Print" environment.

Auto Reduce:

Documents larger than the specified size can be automatically reduced and printed.

  • For example, if you select A3 (297 x 420 mm), an A2 size document will automatically be reduced to A3 and printed.
    If you select A4 (210 x 297 mm), a document larger than A4 will automatically be reduced to A4 and printed.

Color Profile:

Add, edit or delete a color profile in the list. You can add the new color profile provided by the developer to the list and use it.
