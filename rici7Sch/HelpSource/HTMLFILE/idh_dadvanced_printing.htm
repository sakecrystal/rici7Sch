Job Type/Code Dialog Settings Dialog Box

Set whether to display a confirmation dialog box before printing starts.

Display [Classification Code] Dialog Before Printing

Select the check box to display the Classification Code dialog box before printing.

Display [User Code] Dialog Before Printing

Select the check box to display the User Code dialog box before printing.

Display [Change Job Type] Dialog Before Printing

Select the check box to display the Change Job Type dialog box before printing.

Select Always or Display when User ID or Required Password is Blank.

[Change Job Type] Dialog Settings

Select the initial status of the user ID, password, folder password, and user name from select Same as the Set Value in [Change Job Type] or Always Blank.

Save Set Value

Select the check box to save the entered value.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
