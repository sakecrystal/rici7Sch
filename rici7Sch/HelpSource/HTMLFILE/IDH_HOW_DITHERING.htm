Changing the Dithering Pattern

Dithering is a technique where tiny dots are printed in patterns in order to create the illusion of tones and colors that are theoretically impossible to reproduce.

You can change the method used to render these patterns from the original data by following these steps. Select a pattern that matches the actual print image.

Depending on the printer you are using, this function may not be available.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Standard menu on the Detailed Settings tab.

  3. Select Advanced Settings for Adjust Image Quality/Color.

  4. Click the Details... button to open the Details dialog box and click the Adjust Image Quality/Color tab.

  5. In the Dithering: list, select the dithering pattern most suitable for the image.

  6. Make detailed dithering settings for each element of your document (Text:, Graphic:, and Photo:).

  7. Click OK to close the dialog box.

  8. After making any other necessary settings, click OK to close the printing preferences dialog box.

  9. Start printing.
