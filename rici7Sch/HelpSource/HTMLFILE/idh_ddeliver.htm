Output Settings

Use this menu to make settings for output tray or to specify how you want to have prints delivered to the output tray.

Available functions differ depending on the printer or printer driver you are using.

Restore Defaults

Restores the settings on this menu to the default settings.

Output Tray:

Specify an output tray. If you select Printer Default, prints are delivered to the output tray specified on the printer.

Collate:

Sorts the prints into sets when multiple sets of documents are printed. Select a collate method in the list.

Having Prints Sorted

Printer Collate

Ignores the application's collate function and applies the printer driver's collate function.

Application Collate

Applies the collate function set in the application's Print dialog box.

Note:

  • To apply stacking options, select Application Collate and then set the application's collate function to "OFF" in the Print dialog box.

Collate Details...

Opens the Collate Details dialog box, where you can select a collate type.

Rotate Mixed Original Orientation...

When documents containing a mixture of landscape and portrait pages are printed, document pages whose orientation differs from the paper orientation are rotated by 90 degrees. You can change the direction in which the images are rotated.

Reverse Order Printing

When this check box is selected, the document starts printing from the last page. Use this function when prints come out face up in the output tray.

Note:

  • If the application you are using has a similar function, do not make settings with the application's function.

  • If you use this function when applying 2 sided printing to a document with an odd number of pages, the blank last page will also be included in the print count.

Eject Face-up

Select this to deliver printed documents print side up. Use this function with Reverse Order Printing to output a printed document in page order.

Printing a Document Face Up

Note:

  • This function might not be available depending on the folding type you selected in the Fold: list.

Print Crop Marks

Prints crop marks on each page.

Details...

Configure settings for crop marks.

Enable [Stamp] in Printer Settings on the Device

Select the check box to print stamps registered in the device. If you want to print documents without the stamp, do not click the check box.

Note:

  • For details about the stamp setting on the device, see the operating instructions provided with the printer.

Insert Separation Sheet

Select the check box to insert a separation sheet after every set of collated copies. To insert a separator after every two or more sets of copies instead, select the number of sets in the spin box.

Input Tray:

Select an input tray.
