Setting Up Options

Even if options are physically installed in the printer, they cannot be used unless they are configured in the properties dialog box. After installing or uninstalling options, always update the option configuration.

  • If bidirectional communication is operating between the printer and computer, open the printer properties dialog box or click Update Now on the Accessories tab to obtain updates on option configuration automatically.

  • When the Automatically Update Printer Information check box is selected, you can obtain updates on option configuration automatically, simply by opening the printer properties dialog box.

  • If bidirectional communication is not operating, you must update option configuration manually.

Note:

  • If you do not log on as a member of the Administrators or Power Users group, the settings on the Accessories tab are unavailable.

  • Available functions differ depending on the printer or printer driver you are using.

Updating the Option Configuration Manually (When Bidirectional Communication Is Not Operating)

  1. In the Devices and Printers window, open the printer properties dialog box.

  1. Click the Accessories tab.

  2. In the Options area, select check boxes of the options installed.

  3. In the Punch Unit: list, select the type of the punch unit that is installed.

  4. In the Total Memory: list, select the size of the memory that is installed in the printer.

  5. In the Input Tray Settings area, click the Change Input Tray Settings... button to open the dialog box.

  6. In the Input Tray: list, select the input tray where the paper is loaded.

  7. In the Paper Size: list, select the size of the paper loaded.

  8. In the Paper Type: list, select the type of paper loaded.

  9. If the selected input tray is set as unavailable for the Auto Tray Select function at the printer, select the Do not Use Auto Tray Select check box.

  10. In the Paper Position area, select the direction of the paper loaded.

  11. Click the Modify Input Tray/Paper Size button to update or add the information in Input Tray:, Paper Size: and Paper Type: to Input Tray Settings List:.

  12. After configuring all paper trays, click OK to close the dialog box.

  13. Click OK to close the printer properties dialog box.
