Printing with the Folding Unit

You can use the optional folding unit to fold your prints as they come out.

Depending on the printer you are using, this function may not be available.

Note:

  • If the Fold: list is grayed out, check that the optional folding unit is installed on the printer and selected on the Accessories tab.

  • Available fold type changes according to paper orientation, 2 sided setting, and stapling position.

  • The folding function is not available for certain paper sizes and media types. For details, see the operating instructions provided with the printer.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Finishing menu on the Detailed Settings tab.

  3. Select the fold type in the Fold: list.

  4. If necessary, select the Multi-sheet Fold check box.

  • Depending on the combination of fold type and print side that you have selected, this function might not be available.

  1. After making any additional settings, click OK to close the printing preferences dialog box.

  2. Start printing.
