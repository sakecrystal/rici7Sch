Basic

Use this menu to make basic print settings.

Available functions differ depending on the printer or printer driver you are using.

Restore Defaults

Restores the settings on this menu to the default settings.

Orientation

Select the orientation of your document.

Color/ Black and White:

Select whether the document is printed in color or black and white.

Note:

  • Color images will be printed using CMYK toner: Cyan, Magenta, Yellow, and Black. CMY are the three primary subtractive colors.

  • If you want to adjust the print color, use the settings on the Print Quality:Standard and/or Print Quality:Advanced menus.

  • For two-color printing, select Color. Configure two-color printing in the Two-color: list on the Print Quality:Standard menu.

Rotate by 180 Degrees

Prints the image upside down.

For example, use this function if paper loaded in a tray has the top and bottom fixed, and printing with the paper in that direction would otherwise make the image upside-down.

Copies:

Enter the number of copies. Depending on the printer you use, the maximum number of copies may be different.

Document Size:

Select the paper size set in the application. Most applications will specify the paper size automatically, so this setting might not be necessary. To specify a non-standard paper size, select a registered custom paper size. Alternatively, enter the paper size in the Custom Paper Size dialog box, which is accessible through Custom Paper Size....

Note:

  • If you select a document size conflicting with the size set in your application, the document may be printed with the one specified in the application.

  • Custom Paper Size 1 to Custom Paper Size 10 can be registered on the Advanced Options tab in the printer properties dialog box. Depending on the printer you are using, up to 100 custom paper sizes can be registered.

Custom Paper Size...

Opens the Custom Paper Size dialog box, where you can specify a non-standard paper size.

Printing on Custom Size Paper

Reduce/Enlarge:

You can reduce or enlarge the image.

Reducing and Enlarging a Document Size

Off

Do not reduce or enlarge the image.

Fit to Print Size

The document is automatically reduced or enlarged to fit the paper size selected in the Print On: list.

Zoom

Select it if you want to reduce or enlarge the image manually.

Directional Magnification

Enter reduction and enlargement ratios for the vertical and horizontal directions separately.

Zoom:

When you want to zoom in or out the image to print, define the value in % in the spin box. The original size of the document is able to shrink or enlarge from 25% to 400% when printed.

Note:

  • This function is available only if Zoom is selected for Reduce/Enlarge:.

Vertical: / Horizontal:

Enter reduction and enlargement ratios for the vertical and horizontal directions separately by specifying a percentage between 25 and 400% (adjustable in steps of 1%).

Print On:

When you want to print the document on a different size paper than the document size specified in the Document Size: list, select the physical paper size from the list. If you do not want to change the print size, you may select Same as Original Size.
