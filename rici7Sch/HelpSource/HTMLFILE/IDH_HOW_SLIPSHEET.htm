Inserting Different Paper between Pages

Use the following procedure to have paper fed alternately one sheet at a time from two trays. For example, use this function if you print onto OHP transparencies and want to have paper from another tray inserted between each sheet.

Available functions differ depending on the printer or printer driver you are using.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Cover/Slip/Designate menu on the Detailed Settings tab.

  3. Select the Insert Slip Sheet After Every Page check box, and then select the paper tray loaded with paper for the slip sheet in the Input Tray: list.

  4. In the Print Mode: list, select the print mode to use when printing the slip sheet.

  • Slip sheets not printed on is not included in the print count.

  1. Specify the type of printing medium you want to use in the Paper Type in Bypass Tray dialog box when using bypass tray paper as the slip sheet.

  2. After making any other necessary settings, click OK to close the printing preferences dialog box.

  3. Start printing.
