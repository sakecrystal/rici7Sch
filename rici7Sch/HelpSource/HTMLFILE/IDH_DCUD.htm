Printing a Document Using the Colors Applicable to Color Universal Design

This function allows you to convert the colors used in a document to the barrier-free colors applicable to Color Universal Design (CUD).

You can print the document in the converted colors so that people with various types of color vision can distinguish the colors easily.

Note:

  • This function is available only for color printers.

  • The color tone of the print result might differ considerably from the color tone of the original.

  • If you select this function, Barrier-free Color Management is automatically selected for Color Profile: on the Adjust Image Quality/Color tab.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Standard menu on the Detailed Settings tab.

  3. In the Barrier-free Color Management: list, select On.

  4. After making any other necessary settings, click OK to close the printing preferences dialog box.

  5. Start printing.
