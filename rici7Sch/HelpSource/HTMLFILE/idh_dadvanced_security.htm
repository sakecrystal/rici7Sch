Security Settings Dialog Box

Set whether to encrypt print data.

Encrypt Data for Locked Print, Stored Print, and Stored Print (Shared)

Selecting this check box encrypts print data before sending it to the printer.

If Password is NOT Entered

Set whether to cancel printing if a password is not entered in the Change Job Type dialog box when encrypting data.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
