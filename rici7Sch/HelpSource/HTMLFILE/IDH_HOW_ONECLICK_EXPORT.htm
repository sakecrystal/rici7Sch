Saving a Registered One Click Preset as a File

Follow these steps to save printing preferences settings registered to a one click preset as a file.

Note:

  • The following features settings are not stored for one click presets.

User ID, File Name, Password, User Name, Classification Code, User Code, Login User Name, Login Password, Folder Password, watermark items except Print Watermark (On/Off) and selected watermark name, overlay items except Add Overlay (On/Off) and selected overlay name, bitmap items except Add Bitmap (On/Off) and selected bitmap name, color profile items except selected color profile name.

  1. Open the printing preferences dialog box.

  2. Click Manage... on the Frequently Used Settings tab. The Manage One Click Preset List dialog box appears.

  3. Select the one click preset name which you want to save as a file, and then click Export....
    The Save As dialog box appears.

  4. In the File name: box, enter the file name to save the settings.
    The file name extension is ".json".

  5. Click Save.
    The dialog box closes and the setting is saved.

  6. Click OK to close the Manage One Click Preset List dialog box.
