Print Quality:Advanced

Use this menu to adjust the advanced settings that can affect the output quality of the print jobs.

Available functions differ depending on the printer or printer driver you are using.

Restore Defaults

Restores the settings on this menu to the default settings.

Separate into CMYK, then Print in Designated Color Only

Normally full color (CMYK) is used for color printing. However, you can choose to use only specific CMYK color(s).

Printing a Document Using Only Specific CMYK Colors

Vector/Raster:

Specify how document data are printed. The printer driver can send document data as either raster or vector graphic images. All data can be printed as raster images, but most geometric shapes and patterns print faster as vector images.

Vector

Sends document data to the printer as a mixture of vector and raster images.

Note:

  • Not all images can be printed using Vector. If you select Vector and the images do not print as they appear on the computer screen, select Raster and reprint the document.

Raster

Sends all document data to the printer as raster images.

Line Width Adjustment

This function adjusts the thickness of the lines, such as in figures, in dot units.

Print All Text as Black

Prints all text in the print job in black regardless of the original color.

Black Over Print

This function allows black printing on a colored background and helps prevent misregistration. Use this function if your document features black graphics and/or text on a colored background.

Overprinting Black on a Background Color (Black over print)

Adjust Photographs

Corrects the color tone of images taken with a digital camera.

Edge Smoothing

Improves the quality of text and graphics by smoothing jagged outer edges to enhance the appearance of curved lines. If you are printing a document that features images containing fine gradations of tone such as photographs, leave this check box unselected.

Fuser Setting:

If residual gloss appears on the same page or the next page, select High Quality.

High Quality may reduce productivity. If residual gloss does not appear, select Normal.

Change Data Processing

Depending on the application, there may be cases where printing takes a long time, or colors are not reproduced correctly. In this kind of situation, selecting this may rectify the problem.

Since selecting this may cause printing not to function correctly with some applications, you should normally leave this option unselected.

Shift Shading Pattern

Select the check box if the shading pattern appears faint when printing is performed.

Enlarge Shading Pattern

Select the check box if the pattern colors are not printed correctly as the dithering and brush effects interfere.

Bold Text Adjustment

Prints bold-faced characters even bolder.

Make Text Thick

This function increases the thickness of the font to be printed by 1 dot.
