Settings Summary Dialog Box

Displays a settings summary using a list and an image of the printer.

Settings List Tab

Expand

Expands the settings summary list.

Collapse

Collapses the expanded list.

List:

Displays a list of the current print settings.

Tray List Tab

Machine Image

Displays the selected tray as an image.

The currently selected input tray is framed in blue, and the output tray is marked with a blue triangle.

Note:

  • When Auto Tray Select or Printer Default is selected, these marks are not displayed.

Selected Tray List:

Displays the input and output trays information.

OK

Closes the dialog box.
