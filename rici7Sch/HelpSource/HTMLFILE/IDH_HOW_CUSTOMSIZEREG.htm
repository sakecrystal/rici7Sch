Registering Custom Paper Sizes

Use the following procedure to register a frequently used custom paper size.

Note:

  • Up to ten custom paper sizes can be registered. Depending on the printer you are using, up to 100 custom paper sizes can be registered.

  • This setting cannot be selected from the printer properties dialog box when opened from an application.

  1. In the Devices and Printers window, open the printer properties dialog box.

  1. Click the Advanced Options tab.

  2. Click the Register Custom Paper Size... button to open the dialog box.

  3. In Custom Paper Size List:, select an unused size or the size you want to change.

  4. If necessary, in the Name: box, change the name for this size using up to 24 characters.

  5. Enter the length and width of the paper as seen in the graphic.

  • In Width:, enter the size of the paper edge that is vertical relative to feed direction.

  • In Length:, enter the size of the paper edge that is horizontal relative to feed direction.

  1. Click the Modify button to update Custom Paper Size List: with information in the Edit area.

  2. Click OK to close the dialog box.

  3. Click OK to close the printer properties dialog box.
