Perfect Binding Details Dialog Box

This allows you to configure the settings for Perfect Binding.

Perfect binding is a binding method that applies heated glue to printed sheets to form a book block, encloses the book block in a cover sheet, and trims away excess paper to create neat edges.

Available functions differ depending on the printer or printer driver you are using.

Note:

  • For details about perfect binding and the supported paper types and sizes, see the operating instructions provided with the printer.

Binding Position:

Select the binding position.

Binding Paper Source Tray:

Select the paper tray from which the cover sheets will be fed.

Perfect Binding Cutting Options:

Select the type of cutting (edge trimming) method to apply when finishing.

Do not Cut

No cut is applied. Edges are not trimmed.

Fore Edge (Finishing Size)

Only the fore edge is trimmed. Specify the fore edge's finishing size length in the Adjust Cut Position area.

Fore Edge

Only the fore edge is trimmed. Specify the cut length in the Adjust Cut Position area.

3 Edges (Finishing Size)

All edges except the binding edge are trimmed. Specify the finishing size in the Perfect Binding Finishing Size: list. If you select Custom Paper Size, specify the size for I. Width: and H. Length: in the Adjust Cut Position area.

If you want to shift the cut position along the binding edge, specify in J. Along Binding Edge: the distance by which to shift the cut position from the center.

3 Edges

All edges except the binding edge are trimmed. Specify the cut lengths for E. Head Edge:, F. Tail Edge:, and G. Fore Edge: in the Adjust Cut Position area.

Measurement Unit:

Select inch or mm as the measurement unit.

Adjust Image Position

Specify the distance by which you want to shift the print image on the book block.

C. Along Binding Edge:

Specify the distance by which to shift the print image along the binding edge.

D. Across Binding Edge:

Specify the distance by which to shift the print image across the binding edge.

Adjust Cut Position

Specify settings according to the cutting (edge trimming) method selected in the Perfect Binding Cutting Options: list. The shaded settings are unavailable.

E. Head Edge:

Specify the cut length of the head edge.

F. Tail Edge:

Specify the cut length of the tail edge.

G. Fore Edge:

Specify the cut length of the fore edge.

H. Page Length:

Specify the fore edge's finishing size length.

Perfect Binding Finishing Size:

Specify the finishing size in the list.

I. Width:

Specify the size of page width for the custom paper size.

H. Length:

Specify the size of page length for the custom paper size.

J. Along Binding Edge:

If you want to shift the cut position along the binding edge, specify the distance by which to shift the cut position from the center.

OK

Saves the entries and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
