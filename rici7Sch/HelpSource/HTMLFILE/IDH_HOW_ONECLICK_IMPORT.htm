Loading a Printing Preferences Settings File as a One Click Preset

Follow these steps to load a printing preferences settings file as a one click preset. This file would be provided by an administrator, for example.

  1. Open the printing preferences dialog box.

  2. Click Manage... on the Frequently Used Settings tab. The Manage One Click Preset List dialog box appears.

  3. Click Import.... The Open dialog box appears.

  4. Select the file containing the printing preferences settings, and then click Open.
    The printing preferences settings file is loaded and the one click preset is registered.

  5. Click OK to close the Manage One Click Preset List dialog box.
