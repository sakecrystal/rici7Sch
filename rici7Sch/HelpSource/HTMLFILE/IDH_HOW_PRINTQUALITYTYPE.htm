Printing with Optimal Settings for Document

You do not need specialist knowledge of print quality to make the best settings for your document. Use the following procedure to print a document with the optimal settings for its type.

Depending on the printer you are using, this function may not be available.

Note:

  • If you select DTP or Photographic in the Standard Settings of the Adjust Image Quality/Color, depending on the application you are using, images and graphics might be printed in full color (CMYK), even in black and white documents. Characters may also be printed using full color (CMYK) instead of pure Black (K), as some applications send characters as image data to the RPCS driver.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Standard menu on the Detailed Settings tab.

  3. In the Standard Settings of the Adjust Image Quality/Color, select the icon that matches the kind of document you want to print.
    If you select Advanced Settings for Adjust Image Quality/Color, you must then manually set Dithering:, Color Profile:, and Gray Reproduction:.

  1. After making any other necessary settings, click OK to close the printing preferences dialog box.

  2. Start printing.
