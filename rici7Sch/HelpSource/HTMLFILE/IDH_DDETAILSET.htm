Detailed Settings Tab

Use this tab to set details of printing.

Available functions differ depending on the printer or printer driver you are using.

Current Setting

Print Image

Displays a preview image of how the current settings affect the document when it is printed.

Setting Icons

Current settings are displayed using icons. Move your mouse's pointer over icons to see the details.

Document Size: / Print On: / Reduce/Enlarge:

Displays the document size, paper size, and Reduce/Enlarge settings of the current printer.

Settings Summary

Opens the Settings Summary dialog box. In the Settings List tab, shows the details of current settings. In the Tray List tab, shows the list of tray settings and displays the printer configuration as an image.

Register Current Settings...

Opens the Register Current Settings as One Click Preset dialog box. You can register the current settings as a one click preset with its name and comment.

Menu:

Select a menu.

Job Setup

Use this menu to make settings for print job.

Basic

Use this menu to make basic print settings.

Paper

Use this menu to make settings about paper sources.

Cover/Slip/Designate

Use this menu to make settings for covers, slip sheets, or chapter pages.

2 Sided/Layout/Booklet

Use this menu to change the layout when printing, and set 2 sided printing.

Imposition

Use this menu to print a document using an imposition function.

Output Settings

Use this menu to make settings for the output tray or to specify how you want to have prints delivered to the output tray.

Finishing

Use this menu to specify how you want to finish prints after printing.

Print Quality:Standard

Use this menu to adjust the standard settings that can affect the output quality of the print jobs.

Print Quality:Advanced

Use this menu to adjust the advanced settings that can affect the output quality of the print jobs.

Effects

Use this menu to print a watermark text in a document.

Driver Options

Use this menu to provide functions concerned with controls peculiar to the driver.
