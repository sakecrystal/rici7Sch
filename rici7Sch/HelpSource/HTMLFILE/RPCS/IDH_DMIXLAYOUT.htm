Mixed Original Orientations: Layout Dialog Box

When applying layout-printing to documents containing a mixture of landscape and portrait pages, you can specify whether to print document pages whose orientation differs from the paper orientation rotated by 90 degrees or reduced in size without being rotated.

Printout Result:

Specify a printout result when you apply layout-printing to documents containing a mixture of landscape and portrait pages.

Rotate to same orientation as original

Document pages whose orientation differs from the paper orientation are not changed, but rotated to a naturally readable direction.

Reduce without Rotation

Document pages whose orientation differs from the paper orientation are not rotated, but reduced so they can be printed in the same direction.

Page Break

Creates blank pages so document pages of different orientation are not included.

Note:

  • This setting is automatically selected when an item other than Printer Defaults is selected in the Rotate Mixed Original Orientation dialog box opened from the Output Settings menu.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
