Rotate Mixed Original Orientation Dialog Box

When documents containing a mixture of landscape and portrait pages are printed, document pages whose orientation differs from the paper orientation are printed rotated by 90 degrees. Click to select the direction to which you want to rotate those pages.

Available functions differ depending on the printer or printer driver you are using.

Printout Result:

Select a printout result.

Printer Defaults

When applying 2 sided printing or stapling, use this setting to specify the print direction settings correctly.

Rotate to a naturally readable direction

Landscape pages within portrait documents are rotated by 90 degrees leftward for printing. Likewise, portrait pages within landscape documents are rotated by 90 degrees rightward.

Rotate to reverse readable direction

Landscape pages within portrait documents are rotated by 90 degrees rightward for printing. Likewise, portrait pages within landscape documents are rotated by 90 degrees leftward.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
