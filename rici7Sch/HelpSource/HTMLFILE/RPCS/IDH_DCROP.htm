Print Crop Marks Details Dialog Box

Configure settings for crop marks.

Length of Crop Marks:

Specify the length of crop marks.

First Page Only

Select the check box to print crop marks to the first page only.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
