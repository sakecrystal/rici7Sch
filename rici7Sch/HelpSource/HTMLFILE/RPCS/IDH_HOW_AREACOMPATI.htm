Fine-tuning the Printable Area

Use the following procedure to adjust the printable area.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the 2 Sided/Layout/Booklet menu on the Detailed Settings tab.

  3. Select the type of draw area in the Printable Area: list.

  • If you select Maximum, print inside the 5 mm (0.2 inches) margin around the paper edges, the quality might be reduced.

  1. After making any other necessary settings, click OK to close the printing preferences dialog box.

  2. Start printing.

Adjusting the Print Image on the Paper

Use the following procedure to adjust the image position.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the 2 Sided/Layout/Booklet menu on the Detailed Settings tab.

  3. Click Set Image Position... to open the Set Image Position dialog box.

  4. Select the print position in the Image Position: list.

  5. In the Adjust Image Position area, select the direction in which you want to shift the print area in the Direction: list. Change the margins (top, bottom, left, right) according to the selected direction.

  6. Click OK to close the dialog box.

  7. After making any other necessary settings, click OK to close the printing preferences dialog box.

  8. Start printing.
