Printing Images Superimposed on Prints

Follow the procedure below to print an image superimposed on prints. The image is referred to as a watermark.

A watermark made up of a bitmap file (extension .bmp) is referred to as an image watermark.

Note:

  • If you use this function, register the image watermarks in advance.

Having Images Stamped on Prints

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Effects menu on the Detailed Settings tab.

  3. Select the Add Bitmap check box. Click Edit... to open a dialog box.

  4. Enter a name for a new watermark in the Name: box.
    To edit a registered watermark, select the watermark in the Bitmap: list.

  1. In the Path/File Name: box, specify the path and file name for the bitmap data. Alternatively, Browse... to select the bitmap data you want to use.

  2. Select the position where you want to print the watermark in the Position: list.

  3. To adjust the size for the watermark, specify a value in the Size: spin box.

  4. To print the watermark on the first page only, select the First Page Only check box.

  5. To place the watermark over the document, select the Opaque check box. The document under the watermark will not be visible.

  6. To print watermarks repeatedly, select the Repeat check box.

  7. To print watermarks on each original page when Layout or Booklet setting is applied, select the Per Original Page check box.

  8. After specifying the settings, click Add or Update to save the watermark.
    If you click Update, a dialog box appears asking if you want to overwrite the old watermark. Click Yes.

  9. Click OK to close the dialog box.

  10. After making any other necessary settings, click OK to close the printing preferences dialog box.

  11. Start printing.

  • You can select the registered image watermark in the Bitmap: list on the Effects menu.

  • To print the same watermark data using different setting configurations, provide each of the available data combinations with its own watermark data name and register those names in advance.

Deleting an Image Watermark

  1. Open the printing preferences dialog box.

  2. Click the Effects menu on the Detailed Settings tab.

  3. Select the Add Bitmap check box. Click Edit... to open a dialog box.

  4. Select a watermark from the Bitmap: list, and then click Delete.

  5. A dialog box appears prompting for confirmation. Click Yes.

  6. Click OK to close the dialog box.
