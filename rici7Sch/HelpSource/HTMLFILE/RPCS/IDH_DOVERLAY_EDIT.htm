Edit Overlay Dialog Box

Use this dialog box to edit and create Overlay Setting. Use an ".rpo" Overlay Data file.

Note:

  • To print the same Overlay Data using different setting configurations, provide each of the available data combinations with its own overlay data name and register those names in advance.

Overlay Data:

Select an Overlay Setting that you want to edit or delete from the list.

Delete

Deletes the current Overlay Setting.

Edit

Name:

Enter a name for the Overlay Setting.

Path/File Name:

Enter the path and file name for the Overlay Data file.

Browse...

Browse for the file you want to use as Overlay Data.

Add

Adds an edited Overlay Setting as a new Overlay Setting to the list.

Update

Saves the changes after editing an Overlay Setting.

Bring to Front

Select the check box to move the Overlay Data to the front.
The text under the Overlay Data will not be visible.

First Page Only

Select the check box to superimpose the Overlay Data on only the first page of a document.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Help

Displays Help for the dialog box opened.
