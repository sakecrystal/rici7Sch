Color Balance Tab

Use this tab to adjust brightness, contrast, saturation, and color balance.

Available functions differ depending on the printer or printer driver you are using.

Call Preset

Call up the preset color balance.

Note:

  • When you select the preset and click the Call button, the selected color balance is reflected in the image.

Edit Color Balance

Setting Method

Select a component for adjustment.

Note:

  • This function is available only if you select By Each Component for Setting Method.

Before

Displays the image of before color adjustment.

After

Displays the image of after color adjustment.

Brightness:

Specify a value in the spin box to adjust the brightness.

Note:

  • Brightness refers to the brightness of the whole image. Higher brightness levels result in a lighter print image; lower levels, in a darker print image.

Contrast:

Specify a value in the spin box to adjust the contrast.

Note:

  • Contrast refers to the relative contrast between light and dark parts of the print image. Higher contrast levels result in a sharper print image; lower levels, in a softer print image.

Saturation:

Specify a value in the spin box to adjust the saturation.

Note:

  • Saturation is the purity of a color. Increasing saturation makes a color more vivid, while decreasing saturation makes a color duller.

Adjust Each Color

Specify values in the spin boxes to adjust the color balance of red, green, and blue.

Restore Defaults

Restores the settings on this dialog box to the default settings.
