Unauthorized Copy Prevention for Pattern Details Dialog Box

Use this dialog box to make settings for the Unauthorized Copy Prevention for Pattern function.

To open this dialog box, select Unauthorized Copy Prevention for Pattern in Unauthorized Copy Prevention Type on the Effects menu, and then click Details....

Available functions differ depending on the printer or printer driver you are using.

Note:

  • Depending on the unauthorized copy prevention settings, the driver's prevention pattern may be overwritten by the printer's pattern.

Prevention Copy Pattern Print Image

Displays an image of the prevention copy pattern print.

Note:

  • The images for Mask Type: may not be displayed.

  • The images for Layout:, 2 sided:, Booklet:, and Poster: may not be displayed.

Text Type:

Select the text type for the Prevention Text in the list.

Enter User Text:

If you select User Text in Text Type:, enter a user text using up to 64 single-byte characters.

Font:

Select the font type for the prevention text. Only TrueType fonts are available.

Font Style:

Select the font style.

Size:

Specify a value to adjust the size of the prevention text.

Note:

  • If you use a small font, it may not be effective for the prevention copy pattern.

  • A font size of over 50 points is effective, and 70 to 80 points is recommended.

Angle:

Specify a value in this spin box to rotate the prevention text about its central point.

Note:

  • An Angle of 30 to 40 degrees is effective for the prevention copy pattern and is recommended.

Position:

Select a position to enter the prevention text in the list.

Repeat:

Print the prevention text string repeatedly from the top left of the page. Position: is not available.

Line Space:

Specify the line spacing.

Outlined

Prints the text in outline form.

Note:

  • You cannot select the Text Only check box when the Outlined check box is selected.

  • When you select the Outlined check box, the Reverse Patterns: Text/Background check box is automatically selected at the same time.

Text Only

Use only the text pattern when printing with the unauthorized copy prevention. This is useful when the background pattern would make the document hard to read.

Note:

  • You cannot select the Outlined check box when the Text Only check box is selected.

  • You cannot select the check box when the Reverse Patterns: Text/Background check box is selected.

  • You cannot select the Mask Type check box when the Text Only check box is selected.

Reverse Patterns: Text/Background

Exchange the pattern of the text and the pattern of the background.

Note:

  • You cannot select the Text Only check box when the Reverse Patterns: Text/Background check box is selected.

Mask Type:

Select the mask type for the background pattern.

Note:

  • You cannot select the Reverse Patterns: Text/Background check box when a mask type is selected.

  • You cannot select the Text Only check box when a mask type is selected.

Density:

Select the density of the prevention copy text/pattern.

Color:

Select the color that the background text and pattern will print in.

No Pattern Area:

Exclude the specified area from being printed with the pattern.
Use this function for the area such as bar codes.
Specify the values for A:top, B:bttm, C:left, and D:right in mm. The specified range is 1-9999 mm.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
