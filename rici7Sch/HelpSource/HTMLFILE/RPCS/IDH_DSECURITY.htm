Data Security for Copying Details Dialog Box

Use this dialog box to make settings for the Data Security for Copying function.

To open this dialog box, select Data Security for Copying in Unauthorized Copy Prevention Type on the Effects menu, and then select Details....

If a document with embedded copy guard pattern is copied, scanned, and/or stored in the machine with the Copy Data Security unit, the image of the page to be printed is destroyed, and turn the copy's color completely gray.

Note:

  • Depending on the data security for copying settings, the driver's prevention pattern may be overwritten by the printer's pattern.

Copy Guard Text Print Image

Displays an image of the data security for copying text print.

Note:

  • The images for Layout:, 2 sided:, Booklet:, and Poster: may not be displayed.

Text Type:

Select the text type for the data security for copying text in the list.

Enter User Text:

If you select User Text in Text Type:, enter a user text using up to 64 single-byte characters.

Font:

Select the font type for the data security for copying text. Only TrueType fonts are available.

Font Style:

Select the font style.

Size:

Specify a value to adjust the size of the data security for copying text.

Note:

  • If you use a small font, it may not be effective for the data security for copying.

  • A font size of over 50 points is effective, and 70 to 80 points is recommended.

Angle:

Specify a value in this spin box to rotate the data security for copying text about its central point.

Note:

  • An Angle of 30 to 40 degrees is effective for the data security for copying text and is recommended.

Position:

Select a position to enter the data security for copying text in the list.

Repeat:

Print the prevention text string repeatedly from the top left of the page. Position: is not available.

Line Space:

Specify the line spacing.

Outlined

Prints the text in outline form.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
