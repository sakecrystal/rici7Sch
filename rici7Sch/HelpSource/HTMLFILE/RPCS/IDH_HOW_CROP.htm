Printing a Document with Crop Marks

You can print a document with crop marks applied.

This function is useful to print a document that has edges you want to trim off.

Depending on the printer you are using, this function may not be available.

What are Crop Marks?

Crop marks are line markings for trimming documents.

  • Crop marks are printed on front sides when 2 sided printing is applied.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Output Settings menu of the Detailed Settings tab.

  3. Select the Print Crop Marks check box.

  4. Click Details....
    The Print Crop Marks Details dialog box appears.

  5. Specify the length of the crop marks in Length of Crop Marks:.

  • Select the First Page Only when printing crop marks on the first page only.

  1. Click OK to close the dialog box.

  2. After making any other necessary settings, click OK to close the printing preferences dialog box.

  3. Start printing.
