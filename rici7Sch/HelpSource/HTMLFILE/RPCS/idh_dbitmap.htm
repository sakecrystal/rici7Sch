Edit Bitmap Dialog Box

Use this dialog box to edit and create bitmap watermarks. Use bitmap files (extension ".bmp") for bitmap watermarks.

Note:

  • To print the same image watermark data using different setting configurations, provide each of the available data combinations with its own image watermark name and register those names in advance.

Bitmap Watermark image

Displays an image of the bitmap as it appears on the page.

Bitmap:

Select a bitmap watermark that you want to edit or delete from the list.

Delete

Deletes the current watermark.

Edit

Configure settings for a bitmap watermark.

Image data files must be 24 bits or lower bitmaps (extension ".bmp").

Name:

Enter a name for the bitmap watermark.

Path/File Name:

Enter a path and file name for the bitmap image file.

Browse...

Browse for the file you want to use as bitmap watermark.

Size:

Specify a value in this spin box to adjust the size of the bitmap watermark.

Add

Adds an edited watermark as a new bitmap watermark to the list.

Update

Saves the changes after editing a bitmap watermark.

Position:

Select a printing position where you want to print the watermark.

First Page Only

Select the check box to print the bitmap watermark on the first page only.

Opaque

Select the check box to make the bitmap watermark opaque. The image under the watermark will not be visible.

Repeat

Prints bitmap watermarks repeatedly from the top left of the page.

Per Original Page

Select the check box to print the bitmap watermark on each original page even when Layout or Booklet setting is applied.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Help

Displays Help for the dialog box opened.
