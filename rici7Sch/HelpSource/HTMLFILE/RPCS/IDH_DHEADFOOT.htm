Edit Header/Footer Dialog Box

Use this dialog box to edit and create a header/footer.

Date and Time

Select a position and format in each list.

Page Number

Select a position and format in each list.

Text

Select a position and format in each list. If you select User Text in the Format: list, enter the text for the header/footer in the Text: box using up to 32 single-byte or 16 double-byte characters.

Font:

Select a font type for the header and footer text.

Size:

Specify a value in this spin box to adjust the size of the current header and footer text.

Per Original Page

Prints header/footer on each original page even when Layout or Booklet setting is applied.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
