Color Profile Settings Dialog Box

Add, edit or delete a color profile in the list on the Adjust Image Quality/Color tab.
You can add the new color profile provided by the developer to the list and use it.

Color Profile:

Select a color profile pattern in the list.

Delete

Delete the selected color profile pattern.

Edit

Name:

The name entered here will be displayed in the Color Profile: list.

Note:

  • Enter up to 31 single-byte or 15 double-byte characters.

Path/File Name:

Enter a path name and file name for the color profile.

Browse...

Browse and select the color profile data saved on your computer.

Add

Add the color profile data specified and saved with a name to the Color Profile: list.

Update

Update the name or data you want to use for the color profile.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Help

Displays Help for the dialog box opened.
