Set Image Position Dialog Box

Make the print image position settings.

Image Position:

Select the print image position.

Adjust Image Position

Select the direction you want to move the print position. Enter the value you want to increase the margin widths of the left or right margin and the top or bottom margin according to the selected direction.

Measurement Unit:

Select inch or mm as the units of measurement.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
