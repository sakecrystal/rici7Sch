Upgrading the Printer Driver

When upgrading the printer driver, uninstall the old version before installing the new one.

Uninstalling the Printer Driver

This describes how to uninstall the printer driver and delete any custom settings registered. If you want to use any existing custom settings after the upgrade, save them as a printer properties settings file before you start.

For details about saving and registering One Click Preset, see Saving a Registered One Click Preset as a File and Loading a Printing Preferences Settings File as a One Click Preset.

  1. In the Devices and Printers window, select the icon of the printer you want to delete.

  2. Right click the selected printer icon, and then click Remove device.

  • If multiple drivers are registered on one printer icon, click Delete print queue and select the driver to delete.

  1. When a confirmation message appears, click Yes.

  2. The printer icon is deleted.

  3. Select a printer icon, and then click Print server properties.

  1. On the Drivers tab in the Print Server Properties dialog box, select the printer you want to delete, and then click Remove....

  2. Restart Windows.

Installing the New Printer Driver

  1. In the Devices and Printers window, click Add a printer.
    Follow the instructions given by the printer wizard.

  • When the dialog box asking for the machine manufacturer and model appears, click Have Disk... and specify the directory containing the new printer driver files.

  • When you are asked to keep the existing driver or to replace the existing driver with the new driver, click Replace existing driver.

  1. When installation is completed, restart Windows.

  2. Configure installed options and paper trays.

  • This is only necessary if bidirectional communication is not operating.
