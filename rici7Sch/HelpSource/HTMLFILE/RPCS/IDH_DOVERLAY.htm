Register Image Overlay Dialog Box

Register form data for image overlay print.

Registration Number:

Enter a registration number for the image overlay.

Registration Name:

Enter a registration name for the image overlay.

Image Overlay Orientation:

Select the orientation of paper for the image overlay.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Help

Displays Help for the dialog box opened.
