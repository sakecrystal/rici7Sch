Printing a Scanned Data on a Standard Size of Paper

When a document is scanned for printing, its size might be detected as larger than the original, and a printer error might occur.

This function prevents this problem.

Note:

  • If a custom paper size is selected in the Document Size: list on the Basic menu, it is automatically changed to A4.

  • If a custom paper size is selected in Print On:, it is automatically changed to Same as Original Size.

  1. Open the printing preferences dialog box after opening a scanned document from an application.

  2. Click the Driver Options menu on the Detailed Settings tab.

  3. Select the Near Standard Size check box.

  4. Select a standard size in the Document Size: list on the Basic menu.
    You can also select from the Frequently Used Settings tab.

  5. After making any other necessary settings, click OK to close the printing preferences dialog box.

  6. Start printing.
