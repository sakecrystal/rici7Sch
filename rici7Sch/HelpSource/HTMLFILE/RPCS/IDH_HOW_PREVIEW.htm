Displaying the Preview Screen before Printing

You can display the preview screen to check before printing. You can also change some of the settings on the preview screen.

Depending on the printer you are using, this function may not be available.

Note:

  • This function is available only if you have already installed Ridoc Desk Navigator, Ridoc Desk Navigator Lt, or Ridoc IO Navi. For details about the settings, see the Help files for Ridoc Desk Navigator, Ridoc Desk Navigator Lt, or Ridoc IO Navi.

  • Displaying the preview screen with this function may take longer than normal printing. Using this function may also cause your computer to run slowly.

  • This function may not be available in a "Point and Print" environment.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Driver Options menu on the Detailed Settings tab.

  3. Select the Display Preview and Print Screen check box.

  4. Click OK to close the printing preferences dialog box.

  5. The preview screen appears.

  6. Check the preview screen. Change settings as necessary.
    For details about preview screen settings, see the Help files for Ridoc Desk Navigator, Ridoc Desk Navigator Lt, or Ridoc IO Navi.

  7. Click Print to close the preview screen.
