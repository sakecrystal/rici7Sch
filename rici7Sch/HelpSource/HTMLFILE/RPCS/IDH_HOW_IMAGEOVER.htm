Registering Image Overlay

If the hard disk is installed on the printer, you can create and register image overlays.

What Is Image Overlay?

This function allows you to create form data that is usable with page frames, so you can make settings for combining and printing documents.

For details about using image overlay, see the operating instructions provided with the printer.

Note:

  • Printing is not possible using this driver; only image overlay registration can be performed. For details about print-capable emulations, see the operating instructions provided with the printer.

  • Use Web Image Monitor to confirm or delete registered image overlay settings.
    For details, see the Web Image Monitor help.

  • Always return to normal printing after registering an image overlay.

  • Always return to a resolution of 600 dpi, regardless of the driver setting.

  • The toner save function may become invalid.

  1. Open the printing preferences dialog box after creating frame data for use in an application.

  2. Click the Frequently Used Settings tab or the Job Setup menu of the Detailed Settings tab.

  3. Select Store as Image Overlay in the Job Type: list.

  4. Click the Details... button to open the Register Image Overlay dialog box.

  5. Enter a number for the image overlay in Registration Number:.
    Enter a number between 1 and 300.
    Registration is cancelled if you enter a number that is already registered. To register a new image overlay with an existing number, use Web Image Monitor to delete the first registration.

  6. Enter a name for the image overlay in Registration Name:.
    You can enter up to 64 single-byte or 32 double-byte characters except double quotation marks.

  7. Select an orientation in the Image Overlay Orientation: area.

  8. Click OK to close the dialog box.

  9. After making any other necessary settings, click OK to close the printing preferences dialog box.

  10. Start printing.

  11. The image overlay data is saved on the printer's hard disk.
