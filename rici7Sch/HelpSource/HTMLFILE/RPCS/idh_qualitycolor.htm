Adjust Image Quality/Color Tab

Set the image quality and color tone.

Color Profile:

Select a color profile pattern.

If you select By Each Component, different settings can be assigned to each element of text, photographic, and presentation.

Depending on the printer you are using, the available items may vary.

Changing the Color Profiling Pattern

Automatic

Automatically configures the best color profile pattern depending on the appearance of the document to print.

Automatic (Brighter)

Automatically configures the best color profile pattern to be brighter.

Automatic (Darker)

Automatically configures the best color profile pattern to be darker.

Text

Optimizes the colors for text.

Text (Brighter)

Optimizes the colors for text to be brighter.

Text (Darker)

Optimizes the colors for text to be darker.

Photographic

Enhances mid-tone colors similar to those seen in photographs.

Photographic (Brighter)

Enhances mid-tone colors, similar to those seen in photographs, to be brighter.

Photographic (Darker)

Enhances mid-tone colors, similar to those seen in photographs, to be darker.

Presentation

Enhances basic colors used for text and graphics. This setting is best for printing tables, graphs, and presentation materials that contain color.

Presentation (Brighter)

Enhances basic colors used for text and graphics to be brighter.

Presentation (Darker)

Enhances basic colors used for text and graphics to be darker.

CAD

Enhances reproduction of even colors that are true to the original.

POP Display

Prints the color red more vividly. It is an optimal setting for the POP display.

Color Variation 1 (Bright/Yellow)

Enhances colors suitable for portraits.

Color Variation 2 (Dark/Red)

Enhances colors suitable for portraits or food.

Color Variation 3 (Darker/Blue)

Prints the color blue more vividly. Suitable for landscapes.

Color Variation 4 (Dark/Yellow)

Enhances dark-tone colors over the whole area.

Color Variation 5 (Brighter/Red)

Enhances bright-tone colors over the whole area.

Color Variation 6 (Brighter/Yellow)

Enhances brightness and contrast over the whole area.

Color Variation 7 (Darker/Red)

Enhances dark-tone colors and contrast over the whole area.

Off

Prints colors without modification.

Use ICM

Corrects colors using the Windows ICM function.

Using ICM

Expand Gray Recognition

Checks every pixel and prints gray pixels (when the values of RGB are equal or nearly equal) using black toner only.
This setting is available only if you have selected K: Expand Gray Recognition in the Gray Reproduction: list.

Barrier-free Color Management

Converts the colors used in documents to the barrier-free colors applicable to Color Universal Design (CUD).

This setting is available only if you have selected On in the Barrier-free Color Management: list.

Dithering:

Select a dithering pattern suitable for the document image.

If you select By Each Component, different settings can be assigned to each element of text, photographic, and presentation.

Depending on the printer you are using, the available items may vary.

Changing the Dithering Pattern

Automatic

Automatically configures the best dithering method depending on the appearance of the document to print.

Photographic

Performs dithering using a pattern appropriate for photographs.

Text

Performs dithering using a pattern appropriate for text.

Thin lines

Performs dithering using a pattern appropriate for thin lines. Thin colored lines can be seen easily.

CAD

Performs dithering using a pattern appropriate for CAD printing.

Gray Reproduction:

Select the printing method appropriate for black and gray areas of documents.

K (Black)

Prints black and gray using black toner only. Compared to the black printed with CMYK toner, this results in a black that is relatively flatter and purer.

Note:

  • Depending on the application you are using, black and gray images may print with CMYK toner even if K (Black) is selected.

CMY + K

Prints black and gray on all pages using four colors: CMY (Cyan, Magenta, and Yellow) and K (Black).

K(Black) for Text

Prints black and gray text using black toner only.

K (Black) for Gray Pixels Only

Checks every pixel and prints gray pixels (when the values of RGB are equal) using black toner only. Other pixels are printed using CMYK toner.

K: Expand Gray Recognition

Checks every pixel and prints gray pixels (when the values of RGB are equal or nearly equal) using black toner only.

Note:

  • Color Balance is set to Expand Gray Recognition.

Black/Gray by K-Strong UCR

Prints all black and gray objects using black toner only regardless of whether the document is in color or black and white.
This is useful when a black and gray image or scanned black text might print with CMYK toner even if K (Black) is selected.

Color Profile Method:

Specify how to print your color graphics.

By Host System

A color management system (ICM) function or color matching is performed by the host computer before the document is sent to the printer.

ICM is performed by the OS, and color matching by the printer driver.

By Printer

Color matching is performed by the printer.

By Printer Driver

ICM is performed by the printer driver.

ICM Intent:

Specify how color images are created to produce the best looking image on the printed page.

Note:

  • This function is available only if By Printer Driver is already selected in the Color Profile Method: list.

Graphics (Saturation)

Enhances basic colors used for text and graphics. This setting is best for printing tables, graphs, and presentation materials that contain color.

Pictures (Perceptual)

Enhances mid-tone colors similar to those seen in photographs.

Proof (Relative Colorimetric)

Renders colors in an image with the closest colors possible. This is suitable for printing colors that need to be rendered accurately, such as colors in logos. The colors that fall outside the printer color gamut will be rendered to the closest color possible.

Match (Absolute Colorimetric)

Assuming a device-independent color space, this provides a wider range of colors than the printer color gamut.

Restore Defaults

Restores the settings on this tab to the default settings.
