Paper Position in Bypass Tray Dialog Box

You can change the orientation of paper placed on the bypass tray.

Set Paper Position in Bypass Tray

To place paper in portrait orientation, select the Place as Portrait check box. For landscape orientation, select the Place as Landscape check box.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Help

Displays Help for the dialog box opened.
