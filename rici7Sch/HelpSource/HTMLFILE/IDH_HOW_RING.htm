Binding Documents by Ring Comb

If your printer has the Ring Binder installed, the Ring Binding function is available.

The Ring Binding function punches holes in prints and binds them using a ring comb. This function can only punch ring binding holes in prints.

Depending on the printer you are using, this function may not be available.

Note:

  • For details about paper sizes and media types that can be used with this function, see the instructions provided with the printer.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Finishing menu on the Detailed Settings tab.

  3. In the Ring Binding: list, select the ring binding position.

  4. After making any additional settings, click OK to close the printing preferences dialog box.

  5. Start printing.
