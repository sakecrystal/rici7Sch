Saving on Toner When Printing

If your printer supports a toner saving function, this describes how you can save on toner.

Depending on the printer you are using, this function may not be available.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Standard menu on the Detailed Settings tab.

  1. In the Toner Saving: list, select On or specify a toner saving level.

  • Available items might vary depending on your machine model.

  1. If you select User Setting, click the Toner Save User Settings... button to open the dialog box.

  2. Configure Text:, Graphics:, and Photograph: to specify the amount of toner used for each element, and then click OK to close the dialog box.

  3. After making any other necessary settings, click OK to close the printing preferences dialog box.

  4. Start printing.
