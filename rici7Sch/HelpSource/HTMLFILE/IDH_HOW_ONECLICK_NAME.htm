Changing a One Click Preset Name and Comment

Follow these steps to change the name and comment of a one click preset.

  1. Open the printing preferences dialog box.

  2. Click Manage... on the Frequently Used Settings tab. The Manage One Click Preset List dialog box appears.

  1. Select the one click preset name which you want to change in One Click Preset List:.

  • You cannot change the name and comment of the system-provided one click preset.

  1. Change the one click preset name and comment in the boxes below.
    The name can be up to 128 single-byte or 64 double-byte characters.
    The comment can be up to 512 single-byte or 256 double-byte characters. You can insert line breaks.
    Make sure the name and comment have been changed in the list.

  1. Click OK to save the changes and close the Manage One Click Preset List dialog box.
