Accessories Tab

Use this tab to configure the options installed on the printer, and register the available input trays and paper sizes.

Registration of paper sizes enables you to search for a printer loaded with paper of a desired size using the Active Directory function of Windows.

Available functions differ depending on the printer or printer driver you are using.

Machine Image

Displays the printer configuration as an image.

Options

Select the options installed on the printer.
Whenever an option is added, select it in the Options group. Even if an option is physically installed, it will not be available for printing unless it is selected on this tab.

The Punch Unit: list is available when an optional finisher with punch unit is installed and selected. Select a type of punch unit in the list. Depending on the type of unit selected, available punching positions will vary.

Note:

  • If the settings configured on this tab do not match the physical configuration of the printer, you may get unexpected print results.

Total Memory:

Specify the total size that is currently installed on the printer. Or simply clicking Update Now configures the current size of memory if the printer has bidirectional communication.

Input Tray Settings

Change Input Tray Settings...

Opens the Change Input Tray Settings dialog box, where you can configure settings related to the paper in the paper trays.

Input Tray Settings List:

Lists input trays and the size of paper loaded.

Automatically Update Printer Information

Whenever you open the printer properties dialog box, this function queries the printer for its configuration and automatically obtains information about any options installed on the printer.

Note:

  • This function is available only if bidirectional communication between the printer and computer is established by network or direct cable connection. For more information about bidirectional communication, see the operating instructions provided with the printer.

Update Now

Queries the printer for its configuration and automatically obtains information about any options installed on the printer.

Note:

  • This function is available only if bidirectional communication between the printer and computer is established by network or direct cable connection. For more information about bidirectional communication, see the operating instructions provided with the printer.

Restore Defaults

Restores the settings on this tab to the default settings.
