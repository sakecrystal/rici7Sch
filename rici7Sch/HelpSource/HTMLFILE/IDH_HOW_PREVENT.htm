Using Unauthorized Copy Prevention Function (Effects of Prevention for Pattern)

Use this function to embed a text and background pattern in confidential documents. If an unauthorized copy of the document is made, the background pattern and text will be clearly visible. This function makes it easy to identify unauthorized copies.

If documents printed with Unauthorized Copy Prevention for Pattern are copied, scanned, and/or stored, functions are disabled in order to prevent information leakage.

Depending on the printer you are using, this function may not be available.

Note:

  • If you want the document image to be replaced by a solid gray image when printed documents are scanned, copied, or sent to the Document Server without permission, use the Data Security for Copying function.

  • For details about the unauthorized copy prevention function and effects, see the operating instructions provided with the printer.

  • Printing with this function takes longer than normal printing because more data is processed.

  • Depending on the unauthorized copy prevention settings, the driver's prevention pattern may be overwritten by the printer's pattern.

 

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Effects menu on the Detailed Settings tab.

  3. Select the Unauthorized Copy Prevention check box.

  4. Select Unauthorized Copy Prevention for Pattern in Unauthorized Copy Prevention Type.

  5. Click Details... to open the Unauthorized Copy Prevention for Pattern Details dialog box.

  6. Select the text type for the prevention text in the list.

  7. If you select User Text in Text Type: list, enter a user text using up to 64 single-byte characters.

  8. To change the font, font style and font size, specify from Font:, Font Style: and Size:.

  9. To change the angle, specify a value in Angle:.

  10. Select a position to enter the prevention text in Position:.

  11. To repeat text, select the pattern in Repeat:.

  12. Specify the line spacing in Line Space:.

  13. To print the text in outline form, select the Outlined check box.

  14. To use only the text pattern when printing with the unauthorized copy prevention, select the Text Only check box.

  15. To exchange the pattern of the text and the pattern of the background, select the Reverse Patterns (Text/Background) check box.

  16. Select the mask type for the background pattern in Mask Type:.

  17. Select the density and color of the prevention copy text/pattern in Density: and Color:.

  • You can use only black for monochrome printers.

  1. To exclude the specified area from being printed with the pattern, select the No Pattern Area: check box.
    Specify the values for A:top, B:bttm, C:left, and D:right in mm. The specified range is 1-9999 mm.

  2. Click OK to close the dialog box.

  3. After making any other necessary settings, click OK to close the printing preferences dialog box.

  4. Start printing.
