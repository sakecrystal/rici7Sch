Starting Printing from the Last Page

Printing starts from the last page.

Note:

  • If the application you are using has a similar function, do not make settings with the application's function.

  • If you use this function when applying 2 sided printing to a document with an odd number of pages, the blank last page will also be included in the print count.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Output Settings menu on the Detailed Settings tab.

  3. Select the Reverse Order Printing check box.

  4. After making any other necessary settings, click OK to close the printing preferences dialog box.

  5. Start printing.
