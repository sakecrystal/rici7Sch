Fore Edge Cut Details Dialog Box

This function allows you to cut the fore edge when 2 at Center is selected for Staple:.

Depending on the printer you are using, this function may not be available.

Adjust Fore Edge Cut Position:

Specify the cut length of the fore edge. You can adjust the cut size in 0.01 inch or 0.1 mm increments.

Measurement Unit:

Select inch or mm as the measurement unit.

OK

Saves the entries and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
