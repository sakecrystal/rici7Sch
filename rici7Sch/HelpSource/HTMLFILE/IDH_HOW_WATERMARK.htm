Having Text Stamped on Prints

Use the following procedure to have text stamped on prints.

To create, edit, and delete a watermark, see the following procedures:

Printing a Watermark

Editing a Watermark/Creating a New Watermark

Deleting a Watermark

Note:

  • You cannot update or delete system-provided watermarks.

Printing a Watermark

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Effects menu on the Detailed Settings tab.

  3. Select the Print Watermark check box.

  4. Select a watermark in the Watermarks: list.

  • To see the details of the watermark, click Edit.

  1. After making any other necessary settings, click OK to close the printing preferences dialog box.

  2. Start printing.

Editing a Watermark/Creating a New Watermark

  1. Open the printing preferences dialog box.

  2. Click the Effects menu on the Detailed Settings tab.

  3. Select the Print Watermark check box. Click Edit... to open a dialog box.

  4. In the Watermarks: list, select the watermark that you want to edit.
    If you want to register a new watermark, enter a name for it in the Name: box.

  5. Enter the text in the Text: box. The text appears in the preview window.

  6. To change the font, font style and color, specify from the Font:, Font Style:, Color:, and Frame/Outline: lists.

  1. To change the text size, angle, and density, specify a value in the Size:, Angle:, and Density: boxes.

  2. Select a printing position where you want to print a watermark in the Position: list.

  3. To print the watermark on the first page only, select the First Page Only check box.

  4. To place the watermark over the image, select the Opaque check box. The image under the watermark will not be visible.

  5. To print the watermark repeatedly, select the Repeat check box.

  6. To print the watermark on each original page when Layout or Booklet setting is applied, select the Per Original Page check box.

  7. After specifying the settings, click Add or Update to save the watermark.
    If you click Update, a dialog box appears asking if you want to overwrite the old watermark. Click Yes.

  8. Click OK to close the dialog box.

Deleting a Watermark

  1. Open the printing preferences dialog box.

  2. Click the Effects menu on the Detailed Settings tab.

  3. Select the Print Watermark check box. Click Edit... to open a dialog box.

  4. Select a watermark from the Watermarks: list, and then click Delete.

  5. A dialog box appears prompting for confirmation. Click Yes.

  6. Click OK to close the dialog box.
