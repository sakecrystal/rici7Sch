Edit Watermark Dialog Box

Use this dialog box to edit and create watermarks.

Note:

  • You cannot update or delete system-provided watermarks.

Watermark Image

Displays an image of the watermark as it appears on the page.

Note:

  • The displayed watermark image may differ from actual prints.

Watermarks:

Select the watermark that you want to edit or delete from the list.

Delete

Deletes the current watermark.

Edit

Use the following settings to control the appearance of the watermark.

Name:

Enter a name for the watermark.

Text:

Enter the watermark text.

Font:

Select the font type for the watermark text.

Font Style:

Select the font style for the watermark text.

Color:

Select the color for the watermark text.

With black and white printing, the density of gray color changes.

Frame/Outline:

Select an ornament of font style.

Rectangle frames the text with a rectangle.

Circle frames the text with a circle.

Outlined prints the text in outline form.

Size:

Specify a value in this spin box to adjust the size of the current watermark.

Angle:

Specify a value in this spin box to rotate the watermark about its central point.

Density:

Specify a value in this spin box to adjust the density of the current watermark.

Add

Adds an edited watermark as a new watermark to the list.

Update

Saves the changes after editing a watermark.

Position:

Select a printing position where you want to print a watermark.

First Page Only

Prints the watermark on the first page only.

Opaque

Makes the watermark opaque. The image under the watermark will not be visible.

Repeat

Prints watermarks repeatedly from the top left of the page.

Per Original Page

Print watermark on each original page even when Layout or Booklet setting is applied.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Help

Displays Help for the dialog box opened.
