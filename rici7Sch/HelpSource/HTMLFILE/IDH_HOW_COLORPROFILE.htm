Changing the Color Profiling Pattern

Colors on the display are produced using the three colors of RGB, but colors in print are composed of the four colors of CMYK. For printing, RGB color must be converted to CMYK color.

When converting the color, you can adjust the color tones by changing the color profiling pattern.

Note:

  • This function is available only for color printers.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Standard menu on the Detailed Settings tab.

  3. Select Advanced Settings for Adjust Image Quality/Color.

  4. Click the Details... button to open the Details dialog box and click the Adjust Image Quality/Color tab.

  5. In the Color Profile: list, select a color profile pattern.

  1. If you select User Setting, click the Details... button to open the Color Profile Details dialog box.

  2. Make detailed color profile settings for each element of your document (Text:, Graphic:, and Photo:).

  3. Click OK to close the dialog box.

  4. After making any other necessary settings, click OK to close the printing preferences dialog box.

  5. Start printing.

Adding a Color Profile

You can add the new color profile provided by the developer to the list and use it.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Driver Options menu on the Detailed Settings tab.

  3. Click the Color Profile Settings... button to open the dialog box.

  4. In the Name: box, enter a name.
    If you want to edit an existing color profile, select the color profile pattern in the Color Profile: list.

  5. In Path/File Name: or Browse..., specify the path name and file name of the color profile data to be used.

  6. Click Add or Update to save.
    If you click Update, the dialog box to confirm whether or not to save the change appears.

  7. Click OK to close the dialog box.

  8. In the Color Profile: list, select the color profile pattern you added to the list.

  9. After making any other necessary settings, click OK to close the printing preferences dialog box.

  10. Start printing.
