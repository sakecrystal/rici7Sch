Stapling Prints

When a printer is equipped with a finisher, the printed documents can be stapled in individual sets.

Depending on the printer you are using, this function may not be available.

Note:

  • If the Staple: list is grayed out, check that the optional finisher is installed on the printer and selected on the Accessories tab of the printer properties dialog box.

  • When the stapling side selected differs from the binding side selected in the 2 sided: list, staple setting will be automatically set to Off. The binding side and stapling side need to be consistent.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Frequently Used Settings tab or the Finishing menu of the Detailed Settings tab.

  3. Select the stapling position in the Staple: list.

  • When this feature is in use, the printed document is collated automatically.

  1. After making any other necessary settings, click OK to close the printing preferences dialog box.

  2. Start printing.
