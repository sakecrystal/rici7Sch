Printing Multiple Pages on a Sheet

Use the following procedure to have several document pages arranged on each print. This function is called Layout.

Note:

  • When using Layout, a suitable reduction or enlargement ratio is selected automatically based upon the paper size and the number of sheets you want to fit on each page. For example, an A4 document would be reduced in order to fit 2 pages on each sheet of A4 paper. An A5 document would be printed with four A5 document pages fitted on each sheet of A3 paper.

  • If the page orientation varies within a document, a page break will occur before a page where the orientation changes.

  • If an equivalent function is available from your application, turn it off and use the printer driver function.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Frequently Used Settings tab or the 2 Sided/Layout/Booklet menu of the Detailed Settings tab.

  3. Select a layout type in the Layout: list.

  • Click the << Collapse list button if the Layout: list on the Frequently Used Settings tab is not displayed.

  1. In the Page Order: list, select the page order.

  2. Select the Draw Border check box on the 2 Sided/Layout/Booklet menu of the Detailed Settings tab if you want to print dotted separator lines for combined pages.

  3. When specifying the orientation of an original containing a mixture of landscape and portrait pages, click the Mixed Original Orientations... button on the 2 Sided/Layout/Booklet menu of the Detailed Settings tab.

  • Select Printer Defaults for Rotate Mixed Original Orientation on the Output Settings menu in advance.

  1. Click OK to close the dialog box.

  2. After making any other necessary settings, click OK to close the printing preferences dialog box.

  3. Start printing.
