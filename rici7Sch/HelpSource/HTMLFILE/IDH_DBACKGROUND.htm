Background Numbering Details Dialog Box

Use this dialog box to specify the details of the background numbering for confidential documents, for example.
An individual watermark number is printed on each copy. Recording the number to be distributed among other users can prevent unauthorized copies.

Background Numbering Print Image

Displays an image of the background numbering print.

Note:

  • The displayed image may differ from actual prints.

Size:

Select the size for the background numbering text.

Density:

Select the density for the background numbering text.

Color:

Select the color for the background numbering text.

Note:

  • This function is available only for color printers.

Start Number:

Enter the start number for numbering.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
