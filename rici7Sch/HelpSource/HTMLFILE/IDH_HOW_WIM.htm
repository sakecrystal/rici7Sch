Checking the Printer's Status

You can start Web Image Monitor from this printer driver to check the printer's status, manage jobs, and change settings, via a Web browser.

Note:

  • This function is available only if your computer is connected to the printer by the standard TCP/IP (IPv4/IPv6), WSD (IPv4), IPP (IPv4), or Ridoc IO Navi (IPv4/IPv6/IPP) port.
    This function will be unavailable if the IPv6 address you specify includes a number following the % symbol at the end of the address (also known as the "zone identifier" or "scope ID"), or if your computer is connected to this machine through network printer sharing.

  • For details, see the Web Image Monitor Help.

  1. Open the printing preferences dialog box.

  2. Click the Configuration/About Tab.

  3. Click Web Image Monitor... to start Web Image Monitor.
