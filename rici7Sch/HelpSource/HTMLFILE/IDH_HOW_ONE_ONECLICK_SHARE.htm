Sharing One Click Presets

In a multi-user environment, a thin client environment, or a "Point and Print" environment, users can share the one click presets registered by the Administrator.

Note:

  • To make this setting, you must be logged in as an Administrator.

  1. In the Devices and Printers window, open the printer properties dialog box.

  1. Click the Advanced Options tab.

  2. Click Manage..., and the Manage One Click Preset List dialog box appears.

  3. Select the one click preset name which you want to share, and then select the Share check box.

  4. If necessary, click Up or Down to change the display order of the one click presets.

  5. If necessary, change the one click preset name and comment in the boxes below.

  • The name can be up to 128 single-byte or 64 double-byte characters.

  • The comment can be up to 512 single-byte or 256 double-byte characters. You can insert line breaks.

  1. Make sure the settings have been changed in the list. If everything is correct, click OK to save the changes and close the Manage One Click Preset List dialog box.

  2. Click OK.
    The printer properties dialog box closes.
