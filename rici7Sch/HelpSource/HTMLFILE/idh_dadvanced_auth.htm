User Authentication Dialog Box

If the user authentication settings have been made on the printer, you also need to make the user authentication settings on the printer driver. After selecting the User Authentication to On, enter a login name and password in the Authentication dialog box on the Basic tab.

Using User Authentication

Note:

  • For details about user authentication, see the operating instructions provided with the printer.

User Authentication

Select On to print using user authentication.

Display [Authentication] Dialog Before Print

Select this check box to display the Authentication dialog box before printing.

After you enable the function, select whether to display a dialog box every time or to display it only when Login User Name is blank.

Display [Authentication] Dialog Before Printing for Windows Credentials

Select the check box to display the Authentication dialog box for Windows credentials.

Encrypt Login Password

Select the check box to encrypt the login password when sending it to the machine.

Driver Encryption Key:

To encrypt the login password when sending it to the printer, enter the driver encryption key already set on the printer.

Reenter the Confirmation Key:

Enter the login password again for confirmation.

Note:

  • The optional network data protection unit must be installed.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
