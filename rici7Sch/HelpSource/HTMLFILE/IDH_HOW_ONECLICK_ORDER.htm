Changing the One Click Preset Display Order

Follow these steps to change the one click preset display order.

For optimal ease-of-use, change the order according to setting type and how often you use them.

Note:

  • You can only change the settings of one click presets with the icon depending on the setting for Do not allow changing the display order in One Click Preset List on the Advanced Options tab of the printer properties dialog box.

  1. Open the printing preferences dialog box.

  2. Click Manage... on the Frequently Used Settings tab. The Manage One Click Preset List dialog box appears.

  3. Select the one click preset whose order you want to change, and then click Up or Down.

  • Only one click presets with the icon are displayed in the list depending on the settings for Do not allow changing the display order in One Click Preset List on the Advanced Options tabs of the printer properties dialog box.

  1. Click OK to save the changes and close the Manage One Click Preset List dialog box.
