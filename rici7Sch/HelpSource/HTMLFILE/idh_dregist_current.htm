Register Current Settings as One Click Preset Dialog Box

You can register the current settings as a one click preset with its name and comment.

The icon is displayed on the registered one click preset.

Note:

  • You cannot register new one click presets if the Administrator prohibits users from registering them.

One Click Preset Name:

Enter a name for the new one click preset.

The name can be up to 128 single-byte or 64 double-byte characters.

Comment:

Enter a comment for the new one click preset.

The comment can be up to 512 single-byte or 256 double-byte characters. You can insert line breaks.

OK

Saves the entries and closes the dialog box.

Cancel

Cancels the entries.

Help

Displays Help for the dialog box opened.
