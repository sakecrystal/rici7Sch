Rotating the Image by 180 Degrees

Use the following procedure to have the image printed rotated by 180 degrees.

For example, use this function if paper loaded in a tray has the top and bottom fixed, and printing with the paper in that direction would otherwise make the image upside-down.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Basic menu on the Detailed Settings tab.

  3. Select the Rotate by 180 Degrees check box.

  4. After making any other necessary settings, click OK to close the printing preferences dialog box.

  5. Start printing.
