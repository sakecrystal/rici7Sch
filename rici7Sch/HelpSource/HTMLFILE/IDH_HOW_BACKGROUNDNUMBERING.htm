Printing Control Numbers on the Background of Documents

Use this function to add background numbers when printing confidential documents, for example.
An individual watermark number is printed on each copy. Recording the number to be distributed among other users can prevent unauthorized copies.

Depending on the printer you are using, this function may not be available.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Effects menu on the Detailed Settings tab.

  3. Select the Background Numbering check box.

  4. Click Details... to open the Background Numbering Details dialog box.

  5. Specify the size, density, and color from Size:, Density: and Color:.

  • Color: is available only for color printers.

  1. In the Start Number: box, enter the start number for numbering.

  2. Click OK to close the dialog box.

  3. After making any other necessary settings, click OK to close the printing preferences dialog box.

  4. Start printing.
