Manage One Click Preset List Dialog Box (Printing Preferences)

You can change the one click preset display order, delete a one click preset, and change its name and comment.

You can also load a printing preferences settings file as a one click preset and save a registered one click preset as a file.

Note:

  • You cannot change the names and comments of the system-provided one click presets.

One Click Preset List:

Displays the registered one click preset names, comments, and status in the list.

Up

Moves the one click preset display order up.

Down

Moves the one click preset display order down.

Delete

Deletes the selected one click preset.

Import...

You can load a printing preferences settings file provided by an administrator as a one click preset.

Export...

You can save a registered one click preset as a file.

One Click Preset Name:

You can change the name of the one click preset selected in the list.

Comment:

You can change the comment of the one click preset selected in the list.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Help

Displays Help for the dialog box opened.
