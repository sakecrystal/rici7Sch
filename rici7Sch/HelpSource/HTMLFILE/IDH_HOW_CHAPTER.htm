Using Designate/Chapter Function

Use the following procedure to divide a document into chapters and print the first page of each chapter on different paper. You can also specify a special print mode for the first page of each chapter. (Designate/Chapter)
In addition, you can print the selected pages on different paper. (Designated Sheet Print)

Depending on the printer you use, this function may not be available.

Available functions differ depending on the printer or printer driver you are using.

Changing the Print Mode for the First Page of Each Chapter

  1. Create a document containing several chapters in your application and open the printing preferences dialog box.

  2. Click the Cover/Slip/Designate menu on the Detailed Settings tab.

  3. Select the Designate/Chapter check box.

  4. Click Details....
    The Designate/Chapter Details dialog box appears.

  5. In Page Number:, enter the page number on which a new chapter begins.
    You can specify multiple page numbers for multiple new chapters by inserting commas between the page numbers.

  • If you use the application to configure print settings such as page range, odd/even pages only, or page layout, it is likely that this function's page numbering will be affected. For instance, if the document contains 60 pages but in the application you have specified the page range as 41 to 60, the printer will print pages 1 to 20.

  1. In the Print Mode: list, select the print mode for the page specified in Page Number:.

  2. In the Input Tray: list, select the input tray containing the media type to use for the chapter page.

  3. Specify the type of printing medium you want to use in Paper Type in Bypass Tray: when using bypass tray paper as the chapter page.

  4. Click Add to add your definitions of Page Number:, Print Mode:, and Input Tray: to Designate/Chapter Settings List:.

  5. If necessary, make settings for other chapters. The maximum numbers of chapter covers you can specify differs depending on the printer you are using.

  6. When you have completed defining all chapter pages, review the lists in Designate/Chapter Settings List:.

  7. To make modifications, select the item and make corrections in the settings. Click Modify after completing the corrections.

  8. To delete an unnecessary item, click Delete after selecting the one in the list.

  9. After making any other necessary settings, click OK to close the printing preferences dialog box.

  10. Start printing.

Printing the Selected Pages on Different Paper

Note:

  • Depending on the printer you use, the Designate/Chapter function is unavailable.

  1. Create a document containing several chapters in your application and open the printing preferences dialog box.

  2. Click the Cover/Slip/Designate menu on the Detailed Settings tab.

  3. Select the Designate/Chapter check box.

  4. Click Details....
    The Designate/Chapter Details dialog box appears.

  5. In Page Number:, enter the range of pages to specify a new chapter by inserting a hyphen between the page numbers.
    You can specify multiple page numbers for multiple new chapters by inserting commas between the page numbers.

  • If you use the application to configure print settings such as page range, odd/even pages only, or page layout, it is likely that this function's page numbering will be affected. For instance, if the document contains 60 pages but in the application you have specified the page range as 41 to 60, the printer will print pages 1 to 20.

  1. In the Print Mode: list, select Designated Sheet Print.

  2. In the Input Tray: list, select the input tray containing the media type to use for the specified range of pages.

  3. Specify the type of printing medium you want to use in Paper Type in Bypass Tray: when using bypass tray paper for the specified range of pages.

  4. Click Add to add your definitions of Page Number:, Print Mode:, and Input Tray: to Designate/Chapter Settings List:.

  5. If necessary, make settings for other chapters. The maximum numbers of chapters you can specify differs depending on the printer you are using.

  6. When you have completed defining all chapter pages, review the lists in Designate/Chapter Settings List:.

  7. To make modifications, select the item and make corrections in the settings. Click Modify after completing the corrections.

  8. To delete an unnecessary item, click Delete after selecting the one in the list.

  9. After making any other necessary settings, click OK to close the printing preferences dialog box.

  10. Start printing.
