Printing on Both Sides of the Paper

Use the following procedure to print on both sides of the paper.

Depending on the printer you are using, this function may not be available.

Note:

  • Set the same direction as that set in the application. If not, printing will be performed without the correct binding position.

  • Depending on the printer you are using, it is required that the duplex unit be installed.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Frequently Used Settings tab or the 2 Sided/Layout/Booklet menu of the Detailed Settings tab.

  3. Specify how you want to open the bound output in the 2 sided: list.

  • Click the << Collapse list button if the 2 sided: list on the Frequently Used Settings tab is not displayed.

  1. Specify the binding margins as necessary.

  2. After making any other necessary settings, click OK to close the printing preferences dialog box.

  3. Start printing.
