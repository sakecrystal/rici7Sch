Registering One Click Presets

Follow these steps to register one click presets.

  1. Open the printing preferences dialog box.

  2. Click the Frequently Used Settings tab, and then select a one click preset from One Click Preset List: upon which you want to base the new one click preset.

  3. Modify settings on this tab.
    As necessary, you can also modify settings on the Detailed Settings tab.

  • The following features settings are not stored for one click presets.

    • User ID, File Name, Password, User Name, Classification Code, User Code, Login User Name, Login Password, Folder Password, watermark items except Print Watermark (On/Off) and selected watermark name, overlay items except Add Overlay (On/Off) and selected overlay name, bitmap items except Add Bitmap (On/Off) and selected bitmap name, color profile items except selected color profile name.

  1. Click Register Current Settings... to open the dialog box.

  1. Enter a name and comment.
    The name can be up to 128 single-byte or 64 double-byte characters.
    The comment can be up to 512 single-byte or 256 double-byte characters. You can insert line breaks.

  2. Click OK to register the one click preset and close the dialog box.
    The icon is displayed on the registered one click preset.
