Effects

Use this menu to specify whether or not to print a watermark on a document.

Available functions differ depending on the printer or printer driver you are using.

Restore Defaults

Restores the settings on this menu to the default settings.

Unauthorized Copy Prevention

Select the check box to set unauthorized copy prevention.

Unauthorized Copy Prevention Type

Select the prevention effect that you want from the list.

Unauthorized Copy Prevention for Pattern

Use this function to embed a text and background pattern in confidential documents. If an unauthorized copy of the document is made, the background pattern and text will be clearly visible. This function makes it easy to identify unauthorized copies.

Using Unauthorized Copy Prevention Function (Effects of Prevention for Pattern)

Data Security for Copying

If a document with an embedded copy guard pattern is copied, scanned, and/or stored in a machine with the Copy Data Security unit, the image of the page to be printed is destroyed, and turn the copy's color completely gray.

Using Data Security for Copying Function (Destroy the Image and Print gray)

Details...

Opens the dialog box to specify the details of the unauthorized copy prevention.

Background Numbering

Select the checkbox to add background numbers when printing.

Printing Control Numbers on the Background of Documents

Details...

Opens the dialog box to specify the details of the background numbering.

Header/Footer

Select the items that you want to print on header and footer.

Details...

Opens the Edit Header/Footer dialog box, where you can edit and create header and footer.

Print Watermark

Select the check box to print a watermark.

Having Text Stamped on Prints

Watermarks:

Select the watermark that you want to print from the list.

Edit...

Opens the Edit Watermark dialog box, where you can edit and create watermarks.

Add Overlay

Select the check box to print a document with previously created Overlay Data superimposed.

Overlay Data:

Select the Overlay Setting that you want to use.

Edit...

Opens the Edit Overlay dialog box where you can edit and create Overlay Setting.

Add Bitmap

Select the check box to print a bitmap file (extension .bmp) as bitmap watermark.

Bitmap:

Select the bitmap watermark that you want to print from the list.

Edit...

Opens the Edit Bitmap dialog box where you can edit and create bitmap watermarks.
