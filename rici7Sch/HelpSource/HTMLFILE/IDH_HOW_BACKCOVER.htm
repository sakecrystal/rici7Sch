Printing the Back Cover on a Different Type of Paper

Use the following procedure to have the last sheet printed on a different type of paper (for example, paper from a different paper tray) from the other pages.

Depending on the printer you are using, this function may not be available.

Available functions differ depending on the printer or printer driver you are using.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Cover/Slip/Designate menu on the Detailed Settings tab.

  3. Select the Back Cover check box, and then select the paper tray loaded with paper for the back cover sheet in the Input Tray: list.

  • Depending on the printer you use, the input tray selected for the front cover may be always used for the last sheet. In this case, the Input Tray: list is unavailable.

  1. In the Print Mode: list, select the print mode to use when printing the back cover sheet.

  • Back cover sheet not printed on is not included in the print count.

  1. Specify the type of printing medium you want to use in the Paper Type in Bypass Tray dialog box when using bypass tray paper as the back cover sheet.

  2. After making any other necessary settings, click OK to close the printing preferences dialog box.

  3. Start printing.
