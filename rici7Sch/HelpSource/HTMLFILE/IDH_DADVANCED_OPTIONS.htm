Advanced Options Tab

Use this tab to configure further advanced options for printing.

Available functions differ depending on the printer or printer driver you are using.

Manage One Click Presets

Manage...

Opens the Manage One Click Preset List dialog box to specify a one click preset name and comment, or change the display order. You can also share registered one click presets among users and delete existing one click presets.

Do not Allow User to Register Preset

Prohibits users from registering one click presets.

When users open Frequently Used Settings Tab or Detailed Settings Tab, Register Current Settings... is grayed out, users cannot register new one click presets.

Users cannot specify a one click preset name and comment, nor change the display order in the Manage One Click Preset List dialog box (Printing Preferences).

Do not allow changing the display order in One Click Preset List

Prohibits users from changing the order of the system-provided and shared one click presets. Users can only change the order of the one click presets they register. If you clear the check box, you can change the order of all kinds of one click presets.

User Authentication...

Open the User Authentication dialog box to set the user authentication settings.

Job Type/Code Dialog Settings...

Open the Job Type/Code Dialog Settings dialog box to set the printing method for printing.

Security Settings...

Open the Security Settings dialog box to set whether to encrypt print data.

Increase Auto-keep Settings for Applications

Select the check box to apply the print settings of the previous sheet when using an application such as Microsoft® Excel®.

  1. Make the print settings for the first of the four sheets of data.

  2. These print settings are applied to the remaining three sheets.

Collate by Device

If you cannot use the collate function because the optional hard disk or additional memory is not installed in the printer, clear this check box to have the prints sorted into sets according to the application collate settings.

Notify application that both dmPaperLength and dmPaperWidth are not supported

Select the check box to turn off dmPaperLength and dmPaperWidth for DC_FIELDS and dmFields in the driver.

Register Custom Paper Size...

Opens the Register Custom Paper Size dialog box, where you can register custom paper sizes.

Restore Defaults

Restores the settings on this tab to the default settings.
