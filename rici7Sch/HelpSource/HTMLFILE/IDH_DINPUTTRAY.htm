Change Input Tray Settings Dialog Box

Use this dialog box to configure the settings for paper loaded in the paper trays.

Input Tray:

Select an input tray. If you select an optionally installed tray, be sure to specify the tray in the Options group.

Paper Size:

Select a paper size for the tray you have selected in Input Tray:.

Paper Type:

Select a type of paper loaded in the tray.

Note:

  • If you select Plain & Recycled (Auto. for Postcard), it is normally printed as plain paper/recycled paper. If the print paper size is postcard, print with a paper type suitable for postcards.

Do not Use Auto Tray Select

Select the check box if the selected paper tray is set as unavailable for the Auto Tray Select function at the printer.

Paper Position

Select the direction of paper loaded.

Modify Input Tray/Paper Size

Click to update Input Tray Settings List: with the information in Input Tray:, Paper Size:, Paper Type: and Paper Position.

Input Tray Settings List:

Lists input trays and the size of paper loaded.

To add a new entry, select an input tray, paper size, paper type and paper position, and then click Modify Input Tray/Paper Size.

OK

Saves the entries and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Help

Displays Help for the dialog box opened.
