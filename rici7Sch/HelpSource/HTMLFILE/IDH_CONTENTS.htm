Using Help

This system is designed to provide more information about each of the printer features supported by the RPCS printer driver.

Displaying Help for the Printer Driver

  • Click the Help button in the dialog box to display an explanation of the dialog box. Click the Contents tab in the left window to display the table of contents. From here you can view each Help topic.

  • Select the item whose Help topics you want to see, and then press the F1 key.

  • If a question mark button is displayed in the upper right corner of the printing preferences dialog box, click it. Your mouse's pointer will change to a question mark . Move this question mark over the item whose Help information you want to view, and then left-click to display the Help information.

Printing Help Topics

  • To print the currently displayed Help topic, click the Print button at the top.

Note for Printer Driver Tabs and Dialog Boxes

  • The Accessories and Advanced Options tabs are not available in the printing preferences dialog box when accessing from the application's Print dialog box.

  • When you make settings on the Accessories and Advanced Options tabs, you must log on as a member of the Administrators or Power Users group.
