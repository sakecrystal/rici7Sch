Printing Gray Scale in Black and White or in Full Colors

Select black and white or full color to print gray scale.

Note:

  • This function is available only for color printers.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Standard menu on the Detailed Settings tab.

  3. Select Advanced Settings for Adjust Image Quality/Color.

  4. Click the Details... button to open the Details dialog box and click the Adjust Image Quality/Color tab.

  5. In the Gray Reproduction: list, select a printing method for gray scale.

  6. After making any other necessary settings, click OK to close the printing preferences dialog box.

  7. Start the print job.

Selecting to Have Text Printed in Black

This method applies when printing colored text. Use this function to have colored text printed in black: for example, if text clearly visible on the computer screen appears faint when printed.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Advanced menu on the Detailed Settings tab.

  3. Select the Print All Text as Black check box.

  4. After making any other necessary settings, click OK to close the printing preferences dialog box.

  5. Start the print job.

Overprinting Black on a Background Color (Black Over Print)

This function allows black printing on a colored background and helps prevent misregistration. Use this function if your document features black graphics and/or text on a colored background.

Note:

  • This function is available only for color printers.

  • When this function is selected, black and gray areas might be printed with CMYK toner, regardless of the setting specified for Gray Reproduction:.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Advanced menu on the Detailed Settings tab.

  3. Select the Black Over Print check box.

  4. After making any other necessary settings, click OK to close the printing preferences dialog box.

  5. Start the print job.
