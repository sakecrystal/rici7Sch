2 Sided/Layout/Booklet

Use this menu to change the layout when printing, and to set 2 sided printing.

Available functions differ depending on the printer or printer driver you are using.

Restore Defaults

Restores the settings on this menu to the default settings.

Layout:

Select the number of pages printed per sheet. Each document page to be printed on a sheet will be placed in the order selected in the Page Order: list.

Printing Multiple Pages on a Sheet

Page Order:

Select a page layout when two pages or more per sheet is specified in Layout:.

Draw Border

Select the check box to print dotted separator lines for combined pages.

Mixed Original Orientations...

When applying layout-printing to documents containing a mixture of landscape and portrait pages, you can specify whether to print document pages whose orientation differs from the paper orientation rotated by 90 degrees or reduced in size without being rotated.

2 sided:

Prints on both sides of sheets.
Specify how you want to open the bound output in the list.

Binding Margins...

Open the Binding Margins for 2 sided Printing dialog box, where you can specify the binding margins for 2 sided printing.

Booklet:

Prints output so that you can fold it into a booklet.

The pages of your document will be reduced in size and printed side by side, two on each side of each sheet of the original paper size specified in the application. For example, an A4 document will be printed as two A5 images on each side of each A4 sheet.

Printing with a Layout Suitable for Making Booklets

Note:

  • There are only certain sizes of paper applicable for this function.

  • To print at the same size as the original without size reduction, select a paper size that is double that of the original in the Print On: list on the Basic menu.

Off

Disables Booklet printing.

Magazine

Two document pages are reduced and printed side by side on each side of each sheet, and then the whole stack is folded in half, like a magazine.

Mini Book

Each sheet is folded in half separately, and then the folded sheets are stacked and bound.

Page Order:

Select a page layout when Magazine or Mini Book is specified in Booklet:.

Mixed Original Orientations...

When applying booklet-printing to documents containing a mixture of landscape and portrait pages, you can specify the imposition method.

Creep Adjustment...

Prints the document with the creep adjustment function when Magazine is selected in Booklet:.

Using the Creep Adjustment Function

Do not [Fit to Print Size] auto.

Select the check box to print original-size documents side by side at the center of the paper when Magazine is selected in Booklet:.

Printable Area:

If the same document is printed on different printers and results in a different number of pages being printed, adjust the printable area. If you want to print over the whole page surface, select Maximum.

Note:

  • The print inside the 5 mm (0.2 inches) margin around the paper edges might be of reduced quality.

Set Image Position...

Click to open the Set Image Position dialog box and then define the direction of the image position and the width of the margins.

Do not Print Blank Pages

Select the check box to leave blank pages unprinted.
