Job Type Details Dialog Box

Use this dialog box to set a user ID, file name, password and user name for the print job.

This dialog box is accessible by clicking Details... after selecting Job Type: on the Job Setup menu or on the Frequently Used Settings tab.

Depending on the Job Type you selected, the setting items may vary.

User ID:

Select whether to create your own user ID or to use your Windows login name as your user ID. This ID is used to specify the file to be printed or deleted from the printer's control panel. It also identifies individual users in the job history.

The user ID is required for all types of job except Normal Print and Document Server jobs.

Create Own ID

Specify a user ID of your choice in the Enter User ID: box.

Windows Login Name

Auto-specifies your Windows login name as your user ID.

Note:

  • If the number of characters in your Windows login name exceeds 20 single-byte characters, your user ID will only display up to 20 single-byte characters.

Enter User ID:

Enter the user ID using up to eight characters, which are alphanumeric (a-z, A-Z, and 0-9) characters and symbols ('_', '.', '-', '/', and ':').

File Name:

You can optionally set a file name for each file depending on your purpose.

Enter a file name using up to 16 single-byte or 8 double-byte characters except double quotation mark.

Note:

  • This function is available only if you selected Hold Print, Stored Print, Stored Print (Shared), Store and Print, Store and Print (Shared), or Document Server in the Job Type: list.

Password:

Enter a password using 4 to 8 digits when you selected Locked Print in the Job Type: list.

You can also enter a password optionally if you selected Stored Print, Stored Print (Shared), Store and Print, Store and Print (Shared), or Document Server in the Job Type: list.

When Locked Print, Stored Print, or Stored Print (Shared) is selected and the encryption function is enabled, the input range is from 4 to 32 alphanumeric (a-z, A-Z, and 0-9) characters.

User Name:

Enter a user name using up to 16 single-byte or 8 double-byte characters except double quotation marks. This is used to indicate to whom the file in the Document Server belongs.

Set Print Time

Select the check box to print a job at a specified time.

Note:

  • This function is available only if you selected Hold Print in the Job Type: list. Depending on the printer you are using, this function may not be available.

Folder Number:

Enter a number for the folder where you want to store the document, using a value between 0 and 200.

If you specify "0", the document will be stored in the Shared Folder.

Note:

  • This function is available only if you selected Document Server in the Job Type: list.

Folder Password:

If the folder is password-protected, enter the password.

Note:

  • This function is available only if you selected Document Server in the Job Type: list.

OK

Saves the entries and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Help

Displays Help for the dialog box opened.
