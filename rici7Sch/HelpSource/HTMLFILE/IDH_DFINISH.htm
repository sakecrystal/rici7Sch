Finishing

Use this menu to specify how you want to finish prints after printing.

Available functions differ depending on the printer or printer driver you are using.

Depending on the printer you are using, this function may not be available.

Restore Defaults

Restores the settings on this menu to the default settings.

Staple:

Select a stapling position.

Note:

  • Staple requires that the optional finisher be installed on the printer and selected on the Accessories tab of the printer properties dialog box.

  • When this feature is enabled, prints are automatically collated.

  • If the document being printed and stapled contains pages different in size or direction, those sheets printed might not get stapled in the job.

  • Available staple positions vary depending on the punch position and the 2 sided setting.

  • Documents may not be stapled at the slant angle, even when you select Top Left Slant or Top Right Slant. In such a case, the document will be stapled parallel to an edge of the paper.

  • For more information about Staple, see the operating instructions provided with the printer.

Punch:

Select a punching position. Punching positions in the list vary depending on the type of punch unit selected on the Accessories tab of the printer properties dialog box.

Note:

  • Punch requires that the optional finisher with punch unit be installed on the printer and selected on the Accessories tab of the printer properties dialog box.

  • If the document being printed and punched contains pages different in size or direction, those sheets printed might not get punched in the job.

  • Available punch positions vary depending on the stapling position and the 2 sided setting. Check these settings in advance.

  • Available punch positions depend on the settings selected in Orientation and Print On: on the Frequently Used Settings tab or the Basic menu. Check these settings in advance.

  • For more information about Punch, see the operating instructions provided with the printer.

Fold:

Select the fold type that you want the optional folding unit, Z-folding unit, or supported finisher to apply. Fold types in the list vary depending on the type of folding unit selected on the Accessories tab of the printer properties dialog box.

Printing with the Folding Unit

Note:

  • Folding or Z-folding is available only if the optional folding unit, Z-folding unit, or supported finisher is installed on the printer and selected on the Accessories tab of the printer properties dialog box.

  • Available fold type changes according to paper orientation, 2 sided setting, and stapling position.

  • The folding function is not available for certain paper sizes and media types. For details, see the operating instructions provided with the printer.

Multi-sheet Fold

Select the check box to use the multi-sheet folding function. If you enable this function, several sheets are folded at once.

Note:

  • Depending on the combination of fold type and print side that you have selected, this function might not be available.

  • If the original contains more pages than can be folded at once, the job will be canceled. For details about the maximum number of pages that can be folded at once, see the operating instructions provided with the printer.

Ring Binding:

Select a ring binding position. The ring binding function punches holes in prints and binds them using a ring comb. You can also use the ring binding function to punch ring binding holes in prints but not bind them.

Binding Documents by Ring Comb

Note:

  • Ring Binding requires that the optional ring binder be installed on the printer and selected on the Accessories tab.

Perfect Binding

Select the check box to use the optional perfect binder for making perfect bound booklets.

Binding Documents by Perfect Binding

Note:

  • For details about the supported paper types and sizes, see the operating instructions provided with the printer.

Details...

Opens the Perfect Binding Details dialog box, where you can configure the settings for perfect binding.

Fore Edge Cut

If center stapling is selected for Staple:, select the check box to cut the fore edge.

Details...

Opens the Fore Edge Cut Details dialog box, where you can configure the settings for the cut length of the fore edge.

Extended Option:

Select the finishing method if you want to finish prints after printing by using the 3rd vender's finisher connected to the machine.
