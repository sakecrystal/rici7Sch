Printing in Color or Black and White

Use the following procedure to print a document in color or black and white.

For greater darkness in black and white images, the use of Black and White printing is recommended.

Note:

  • This function is available only for color printers.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Frequently Used Settings tab or the Basic menu of the Detailed Settings tab.

  3. In the Color/ Black and White: list, select Color or Black and White as necessary.

  4. If you want to adjust the print quality, click the Print Quality:Standard, Print Quality:Advanced menus on the Detailed Settings tab, and then configure the necessary settings.

  1. After making any other necessary settings, click OK to close the printing preferences dialog box.

  2. Start printing.
