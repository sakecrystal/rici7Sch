Collate Details Dialog Box

Select the collate type applied when the collate function is selected.

Note that the collate types that are available will vary depending on your printer or the configuration.

Collate Type:

Collate

Print sets are all delivered in the same orientation.

Rotating Collate

Every other print set is rotated by 90 degrees and delivered to the output tray. Rotating Collate is available only if paper of the same size is loaded in in the trays (in portrait or landscape orientation).

Note:

  • If you specify a tray other than Auto Tray Select for the input tray, Rotating Collate is not available.

Shift Collate

Print sets are alternately shifted when delivered to the output tray. Stapled print sets are not shifted.

OK

Saves the changes and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Help

Displays Help for the dialog box opened.
