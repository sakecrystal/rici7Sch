Paper

Use this menu to make settings about paper sources.

Available functions differ depending on the printer or printer driver you are using.

Restore Defaults

Restores the settings on this menu to the default settings.

Input Tray:

Select an input tray.

Note:

  • If you cannot select the desired input tray, check that all installed options are configured on the Accessories tab of the printer properties dialog box.

  • If you select Auto Tray Select, the printer uses paper from another input tray that contains paper of the same size and type if there is no more paper left in the current tray.

Position in bypass tray...

Select the orientation of the paper placed on the bypass tray.

Paper Type:

Specify the type of printing medium you want to use. Available media types differ depending on the printer you are using.

Note:

  • If you select Plain & Recycled (Auto. for Postcard), it is normally printed as plain paper/recycled paper. If the print paper size is postcard, print with a paper type suitable for postcards.

[Tab Stock] Printing

Select this in order to print a portrait document with the tab on the right and a landscape document with the tab on the top.

Shift Print Position for [Tab Stock]

Prints the image by shifting the image toward the tab so that you can print on the tab and also have extra space on the opposite side for stapling or punching.

Letterhead Setting:

Specify whether or not to print using the letterhead setting.
This function enables you to print correctly on paper that has a fixed print side or print direction such as letterhead paper, for example.

Note:

  • For details about loading in the paper tray paper that has a fixed print side or print direction, see the operating instructions provided with the printer.

Printer Default

Follows the printer settings.

Off

Disables the letterhead printing.
When two-sided printing with an odd paged job is enabled, letterhead paper might not be printed correctly.

Auto Detect

Performs the letterhead printing when paper that has a fixed print side or print direction is specified in Paper Type:.

On (Always)

Always performs the letterhead printing.

Apply [Letterhead Setting] to 1 sided print

Specify whether or not to apply the letterhead setting to one-sided printing.
Apply this to one-sided printing to print on letterhead paper correctly.
