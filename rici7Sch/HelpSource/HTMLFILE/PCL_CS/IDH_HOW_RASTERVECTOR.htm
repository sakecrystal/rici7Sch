Printing the Whole Page as Image Data

Use the following procedure to print the whole page as image data. This allows you to get print results that resemble the display image more closely, but since more data has to be processed printing takes much longer. Use this feature if the printed image differs from the display image.

Note:

  • Whatever the setting made in Gray Reproduction: on the Adjust Image Quality/Color tab, black or gray areas are printed with CMYK toner.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Advanced menu on the Detailed Settings tab.

  3. In the Vector/Raster: list, select Raster.

  4. After making any other necessary settings, click OK to close the printing preferences dialog box.

  5. Start printing.
