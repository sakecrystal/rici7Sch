Authentication Dialog Box

Use this dialog box to enter a login user name and login password already set on the printer or server for the user authentication. If the user authentication settings have been made on the printer, you also need to make the user authentication settings on the printer driver. Otherwise, you cannot use the printer.

Note:

  • If you do not enter a valid login user name and login password, printing will not start.

Login User Name:

Select a type of login user name for user authentication.

Defined User ID

Specify a login user name already set on the printer or server for user authentication.

Windows Login Name

Auto-specifies your Windows login name as your user ID.

Enter Login User Name:

Enter a login user name already set on the printer or server for user authentication.

Login Password:

Enter a login password already set on the printer or server for user authentication.

Confirmation Password:

Enter the login password again for confirmation.

OK

Saves the entries and closes the dialog box.

Cancel

Closes the dialog box without saving any changes.

Restore Defaults

Restores the settings on this dialog box to the default settings.

Help

Displays Help for the dialog box opened.
