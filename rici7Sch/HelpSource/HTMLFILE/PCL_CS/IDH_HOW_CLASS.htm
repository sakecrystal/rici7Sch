Registering Classification Code and User Code

Use the following procedure to register classification code and user code.

Registering a Classification Code

If you register classification codes, the printer logs the number of prints made under each code.

You can register classification codes to individual users and purposes, enabling you to monitor printer usage by each.

For example, you can manage accounts according to individual clients or account titles.

Depending on the printer you are using, this function may not be available.

Note:

  • Depending on the classification code setting specified on the printer, jobs without a classification code might be canceled. For details, see the operating instructions provided with the printer.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Job Setup menu of the Detailed Settings tab.

  3. In the Classification Code: box, enter a classification code using up to 32 characters (a-z, A-Z, 0-9, "_", "-").

  4. After making any other necessary settings, click OK to close the printing preferences dialog box.

  5. Start printing.

Registering User Code

When user codes are registered, the number of prints made under each user code is recorded in the printer. Setting a user code, for example, for each department or individual enables you to track their printer usage.

Note:

  • When the user authentication function is used, user code setting becomes invalid.

  • If a user code is set in an external application (such as utility software), you cannot set a user code in this driver.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Job Setup menu on the Detailed Settings tab.

  3. In the User Code: box, enter a user code using up to eight digits.

  4. After making any other necessary settings, click OK to close the printing preferences dialog box.

  5. Start printing.
