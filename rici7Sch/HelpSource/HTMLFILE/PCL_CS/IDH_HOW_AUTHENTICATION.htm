Using User Authentication

If the user authentication settings have been made on the printer, you also need to make the user authentication settings on the printer driver.

Depending on the printer you use, this function may not be available.

What Is User Authentication?

With user authentication, only users who are registered on the printer or server can print using the printer. You need to make the login user name and login password settings for a user to enable that user to print. Users who are not registered on the printer or server cannot use the printer.

Follow the steps to utilize the User Authentication function.

Note:

  • For details about user authentication, see the operating instructions provided with the printer.

  • When the user authentication function is used, the user code setting on the Job Setup menu of the Detailed Settings tab becomes invalid.

  1. In the Devices and Printers window, open the printer properties dialog box.

  1. On the Advanced Options tab, click User Authentication... to open the User Authentication dialog box.

  • When you make settings on the Advanced Options tab, you must log on as a member of the Administrators or Power Users group.

  1. Select On for User Authentication.

  2. Select the check box for Display [Authentication] Dialog Before Printing or Display [Authentication] Dialog Before Printing for Windows Credentials.

  3. Select the Encrypt [Login Password], enter the driver encryption key already set on the printer and click OK.

  4. Click OK to close the printer properties dialog box.

  5. In the Devices and Printers window, open the printing preferences dialog box.

  6. On the Basic tab, click Authentication....
    The Authentication dialog box appears.

  1. Select a type of login user name, and then enter a login user name and password that is already set on the printer or server for user authentication.

  • If you do not enter a valid login user name and login password, printing will not start.

  1. Click OK to close the dialog box.

  2. Click OK to close the printing preferences dialog box.
