Changing Bitmap Printing Resolution and Speed

When printing documents that contain high resolution bitmap images, printing takes longer due to the larger amount of data that must be processed. By changing the method for bitmap rendering, you can specify whether to give priority to quality or speed .

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Standard menu on the Detailed Settings tab.

  3. In the Print Priority: list, select an image processing priority.

  4. After making any other necessary settings, click OK to close the printing preferences dialog box.

  5. Start printing.

Changing the Image Data Processing Method

Depending on the application, there may be cases where printing takes a long time, or colors are not reproduced correctly. In this kind of situation, changing the image data processing method may rectify the problem.
Since changing the image data processing method may cause printing not to function correctly with some applications, you should normally leave this option unselected.

  1. Open the printing preferences dialog box after creating a document in an application.

  2. Click the Print Quality:Advanced menu on the Detailed Settings tab.

  3. Select the Change Data Processing check box.

  4. After making any other necessary settings, click OK to close the printing preferences dialog box.

  5. Start printing.
